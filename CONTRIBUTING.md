# Contributing

Thank you for helping improve Xynigo Sourcing.

## Before opening a pull request

1. Use only synthetic, anonymized fixtures.
2. Do not include credentials, cookies, tokens, proxy URLs, internal IDs,
   customer/order data, screenshots, or browser snapshots.
3. Preserve explicit confirmation gates around platform writes.
4. Add or update tests for behavior changes.
5. Run `python -m unittest discover -s tests`.

Open an issue before large architectural changes. Keep pull requests focused
and document any platform assumptions that were verified only in a test
environment.
