## 当前卡点

1. **未签名安装包**：Windows Smart App Control 无法按单应用放行；当前只能内部手动关闭或放行，长期必须签名。
2. **版本线分裂**：Latest 是 v0.12.6，prerelease 标签是 v0.12.7 基础提交，线上却使用 hotfix11/hotfix7。
3. **真实设备测试资源有限**：只有两位实际使用同事承担生产式测试，没有独立测试人员。
4. **主工作区较脏**：内部候选、已上线热修复和业务输出并存，盲目合并或 `git add -A` 风险高。
5. **生产仍未授权**：当前域名、服务器和数据库都是共享测试；不能把真实测试通过解释为生产上线。
