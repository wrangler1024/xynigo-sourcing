# Xynigo Sourcing v0.12.6 本地执行器通道内部测试版

v0.12.6 面向当前两位在用同事开放真实工作电脑测试，新增云端 Web 与本地执行器设备通道，并同时提供 Windows/macOS 标准安装包和绿色包回退入口。

## 新版本怎么使用

1. 在云端 Web 打开“系统管理 → 本地执行器”，选择本机系统并下载标准安装包。
2. 下载前核对页面显示的文件名、大小和 SHA-256。标准包当前未使用平台可信签名，只限内部测试；按飞书开发群教程手动确认 Windows SmartScreen 或 macOS Gatekeeper 提示。
3. Windows 安装后从开始菜单打开 Xynigo 状态中心；macOS 从“应用程序”打开 Xynigo Sourcing，并保持 Terminal 执行器窗口运行。
4. 首次使用可迁移旧绿色包数据。Windows 在安装向导选择旧目录；macOS 首次启动选择旧绿色包目录。迁移只复制配置、日志、运行数据和导入文件，不覆盖标准版已有数据。
5. 回到云端生成 5 分钟一次性配对码，使用“一键打开并配对”；若系统协议没有拉起程序，使用安装包内的手动配对入口。
6. 页面显示“已配对并收到真实心跳”后，先读取本机配置，再保存需要修改的非敏感字段。
7. 遇到问题请在开发群提供发生时间、设备名称、页面提示和脱敏错误码，不发送账号、密码、Cookie、Token、代理链接或完整收件信息。

## 安全与范围

- 标准安装包尚未使用可信代码签名和 Apple 公证，当前只用于内部快速迭代测试。
- `xynigo://` 仅允许启动、唤醒和一次性配对，不允许承载业务任务或长期凭证。
- 本轮设备通道只执行配置读取与保存；真实下单、建环境和物流任务仍未接入云端调度。
- 绿色包仍可使用，且不会静默安装或强制升级。
