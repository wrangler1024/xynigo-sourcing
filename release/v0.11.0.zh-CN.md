# Xynigo Sourcing v0.11.0 协同测试版

v0.11.0 以 GitHub 稳定版 v0.10.0 为本地执行器基线，合并当前飞书认证、组织权限、云端采购中心和店小秘提单助手本机桥。该版本供共享测试环境的全体现有测试用户统一使用，不是生产版本。

## 合并能力

- 保留 v0.10.0 的订单物流查询、账号注册、买家号库、环境创建、安全并行、环境资源预占及 HubStudio Local API 调用闸门。
- 增加“小犀代采”飞书 OAuth、待审批成员、内置管理员/超级管理员、角色权限、会话撤销和审计。
- 增加 PostgreSQL 采购单、草稿/正式提交、采购认领、分单保存和采购执行队列；Alembic head 为 `0004_procurement_execution_test`。
- 增加店小秘提单助手本机安全桥，扩展只持有与扩展 ID/Origin 绑定的进程内配对令牌。
- 云端 Bearer 会话继续只保存在本机系统安全存储；浏览器、插件和 URL 均不可获得该会话。

## 本地执行器兼容边界

- 继续使用原 `purchase_tool` 启动入口、回环 HTTP 服务、HubStudio/CDP 集成和既有配置文件。
- 安全并行默认关闭；开启后仍只允许物流查询与一个环境创建任务并行，同环境资源冲突在执行前返回 409。
- HubStudio 与飞书真实写入的二次确认、查重、幂等恢复及写后回读保持不变。
- 现有 8767/8771 服务不由版本合并自动停止、替换或重启。

## 测试渠道限制

- 只连接 `https://xynigo.samforo.icu`，不得连接生产服务器或正式数据库。
- 真实 HubStudio 下单、SHEIN 写入、店小秘审核、正式飞书 Base 同步和批量数据删除均未随本版本开放。
- 飞书同步 Worker 尚未部署；`syncStatus=pending` 只表示 PostgreSQL Outbox 已排队。
- 当前用户仅一至两名，不再分批灰度；全部现有测试用户统一更新到 v0.11.0。新增普通成员仍必须经过待审批、角色分配和批准流程。

## 回退

- 本地执行器可回退到 GitHub v0.10.0 安装包；回退前保留配置、日志和运行数据。
- 店小秘提单助手可在扩展管理页停用或切回上一包；它不会修改店小秘审核状态。
- 云端测试部署失败时只回滚 `/opt/xynigo-auth-test` 应用镜像，不回退已经包含业务数据的 PostgreSQL 迁移。
