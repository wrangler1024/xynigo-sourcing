# Xynigo Sourcing v0.17.15

- 导入分单以 XYP2 采购备注的链接、规格和数量为准，销售 SKU、颜色或尺码差异不再阻断整单。
- 提单助手自动绑定销售来源；手工明细可选择来源或额外采购，拆购共享图片且销售商品金额只计一次。
- 历史 SKU 数量尾缀按明确来源兼容；无法关联的商品金额和图片可留空导入，并允许按整单选择只导入通过的订单。
- 飞书协作表保留完整采购 URL 纯文本，回读验证实际值，便于复制完整采购参数。
- 登录策略沿用既有自动续期和到期规则；运营重复登录问题继续收集版本、时间和浏览器重启情况。

## 使用说明

1. 先升级云端服务，再刷新店小秘提单助手 v0.12.7；旧插件和旧 XYP2 备注继续兼容。
2. 采购可以重新上传原店小秘 Excel。采购规格以备注为准，来源不明确时不猜配销售金额或图片。
3. 常规明细自动绑定销售来源；新增手工明细选择销售来源或额外采购，更换采购链接不改变已确认来源。
4. 新关联需在提交前明确，草稿可保留待确认状态。同一来源拆购时保留唯一销售金额归属，可更改关联、删除或撤销。
5. 已导入历史数据继续受查重和采购数据保护规则约束；本版不自动改写历史订单。

## 发布范围

延续内部 test 更新通道及 GitHub Prerelease。本版无新增数据库迁移，不延长登录策略。Windows 与 macOS 安装包按同一源码提交构建，发布前固定实际产物校验值。
