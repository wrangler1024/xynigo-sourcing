# Xynigo Sourcing v0.6.0

v0.6.0 将“小犀代采”的品牌视觉正式落地到真实系统，同时保留 v0.5.1 的三大业务模块、数据安全边界和双平台在线更新能力。

## 主要更新

- 全新 Xynigo VI WebUI：深海军蓝、小犀青、包裹黄和珊瑚红组成统一品牌色系。
- 新增可折叠任务侧栏；窄窗口自动折叠，也可随时手动展开或收起。
- 模块入口改为物流查询、买家号注册和买家号建环境的语义化图标。
- 吉祥物英文名正式确定为 Xyni，主视觉口令为“Xyni, GO!”。
- “重查异常行”和“导出 Excel”集中到查询结果操作区，异常处理入口更清晰。
- 重新设计卡片、表格、进度、按钮、弹窗和响应式布局，不改变原有 API 与任务执行逻辑。
- Windows 与 macOS Apple Silicon 继续提供完整绿色包和安全在线更新。

## 更新说明

现有 v0.5.0 或 v0.5.1 绿色包启动后会自动发现 v0.6.0。输入 `Y` 即可下载、校验、备份并更新；本机 `config.json`、日志、运行数据和用户导入文件会继续保留。

> macOS Intel 不在维护范围内。更新功能不会将本机配置、日志或业务数据上传到 GitHub。
