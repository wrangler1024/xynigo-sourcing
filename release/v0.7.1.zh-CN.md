# Xynigo Sourcing v0.7.1

v0.7.1 是订单物流查询 Excel 导出的紧急兼容修复，重点解决轨迹图片漂浮在单元格上方、无法随单元格区域批量复制的问题。

## 主要更新

- 轨迹截图从 DrawingML 浮动图片改为 Excel 真正的“图片置于单元格”。
- 连续框选多行轨迹截图单元格后，可以随单元格区域一次性复制、粘贴多张图片。
- 图片二进制仍直接封装在 `.xlsx` 文件内，不读取外部文件路径，也不依赖网络图片链接。
- 保留现有主表布局、筛选、冻结表头、边框、缩略图尺寸，以及环境名、出口 IP 等完整审计字段。
- 单元格图片采用 Microsoft Excel `_localImage` 富数据结构；适用 Microsoft 365 和 Excel 2024。旧版 Excel 与 WPS 的显示及复制行为不作保证。
- Windows 与 macOS Apple Silicon 同步提供更新包。

## 在线更新验收

在旧版页面右上角点击“检查更新”，发现 v0.7.1 后按提示确认；程序应完成下载、SHA-256 校验、备份、替换与重启，并保留本机 `config.json`、日志、运行数据和用户导入文件。

更新后完成一次订单物流查询并导出 Excel。使用 Microsoft 365 或 Excel 2024 打开文件，确认轨迹图片位于单元格内；连续框选至少两张图片对应的单元格，复制到新工作表，图片应随单元格区域一起粘贴。
