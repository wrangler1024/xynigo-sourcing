# Xynigo Sourcing v0.13.16 执行设备记忆与 HubStudio 状态修复测试版

v0.13.16 修复云端工作台刷新后重复选择执行器，以及 HubStudio 关闭后仍被显示为在线的问题。

## 主要变化

- 本次选择的执行设备自动保留在当前浏览器会话，刷新页面无需重新选择。
- “记住此浏览器的默认设备”继续控制跨会话长期记忆；临时设备选择不会覆盖长期默认。
- 执行器每次云端心跳都强制执行本机 HubStudio 状态探测，不复用旧的在线缓存。
- 先检查本机 HubStudio 进程，再检查 Local API；残留的本地监听端口不能把已关闭客户端误报为在线。
- 状态展示区分“状态未知”“未启动”“已启动但 API 未就绪”和“已启动且可用”。
- 没有执行器上报时，云端不会直接探测浏览器所在电脑的回环端口，也不会推断 HubStudio 在线。
- Windows 与 macOS 从同一 Git 基线同步构建发布。

## 测试边界

- 当前安装包仍未签名，仅用于内部测试。
