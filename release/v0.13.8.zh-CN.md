# Xynigo Sourcing v0.13.8 数据源管理测试版

v0.13.8 补齐桌面客户端的数据源注册表管理能力，也是 v0.13.7 在线更新链路的首个功能迭代版本。

## 主要变化

- 数据源卡片新增“查看详情”“认领为我的”“重新配置”和真实“重新验证”。
- 详情页显示类型、归属、工作表、读取范围、启用状态和关联环境数量。
- 支持修改数据源显示名称和启用状态，保存时执行 revision 冲突校验。
- 旧个人速填表认领后自动成为当前飞书成员的个人默认数据源。
- 已有数据源可重新粘贴飞书链接、选择工作表并校验；替换时自动迁移采购员默认值、团队默认值和环境映射。
- 团队数据源可设置或取消团队默认。
- 完整 Spreadsheet Token、Sheet ID 和表格内容继续只保留在本机，不通过详情 API 或前端回显。
- 继续支持 Windows 静默在线更新和 macOS 系统安装器在线更新、SHA-256 校验及自动重启。

## 升级说明

- 已安装 v0.13.7 的客户端可通过“诊断与维护 → 检查更新”升级。
- macOS v0.13.6 及更早版本需先手动安装 v0.13.7 或直接覆盖安装 v0.13.8。
- 更新保留现有配置、日志、运行数据、数据源注册表和设备配对。
- 当前候选安装包仍未签名，仅用于内部测试。
