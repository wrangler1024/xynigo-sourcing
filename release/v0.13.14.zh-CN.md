# Xynigo Sourcing v0.13.14 运行环境交互优化测试版

v0.13.14 优化云端工作台的导航与多设备选择逻辑，让功能页签优先展示，并避免账号下其他在线电脑被误认为当前电脑。

## 主要变化

- 顶部仅保留业务功能页签和账号入口，云端、执行器与 HubStudio 状态统一移到底部运行状态栏。
- 运行环境改为右侧覆盖式面板，展开时不再压缩或重排主功能区。
- 多设备账号必须明确选择本次任务使用的执行器；未选择时禁止启动依赖本机的查询任务。
- 所选设备离线或 HubStudio 未连接时不会自动切换到其他在线设备。
- 可按浏览器记住默认执行器；新电脑首次登录仍保持“未选择执行器”。
- 移除遮挡左侧菜单的“小犀提示”，保留“小犀助手 → 采购协作导入”原有功能和权限逻辑。
- 系统管理入口继续保留，窄屏菜单改为横向滚动，避免后排入口不可访问。
- Windows 与 macOS 从同一 Git 基线同步构建发布。

## 测试边界
