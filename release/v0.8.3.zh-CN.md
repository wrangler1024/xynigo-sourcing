# Xynigo Sourcing v0.8.3

v0.8.3 是飞书生产台账连接验证补丁，解决重新配置台账后名称长期显示“待连接验证”、连接问题难以区分字段问题，以及高级权限未开放目标表时提示不明确的问题。

## 修复与优化

- 进入系统设置时，如果应用凭证与台账目标已经配置但名称尚未验证，系统会自动执行一次只读名称刷新。
- 保存飞书配置后立即验证当前 Base 与数据表名称；配置本身保存成功但连接验证失败时，页面会明确区分两种结果。
- “只读检查统一台账字段”升级为“重新验证连接与字段”，依次刷新 Base／数据表名称并校验统一台账字段契约。
- 新增独立的只读目标名称刷新接口，不读取记录、不创建、修改或删除飞书数据。
- 当企业应用能访问 Base 但目标数据表被高级权限过滤时，错误明确提示在多维表格高级权限中为“小犀代采”应用开放该表。
- 字段契约校验失败时仍保留已成功获取的 Base 与数据表名称，方便区分“连接权限失败”和“字段结构不一致”。

## 安全与兼容性

- 名称刷新和字段预检均为只读操作；本版本发布过程不执行真实 HubStudio 或飞书业务写入。
- App Secret、访问令牌、Base Token、Table ID、记录 ID、完整台账链接、密码和 Cookie 不通过公开配置接口或错误信息回显。
- 自动化测试只使用 FakeHub、FakeLark、`example.test` 和公开脱敏标识。
- Windows x86_64 与 macOS Apple Silicon 同步提供更新包；macOS Intel 不在维护范围。

## 在线更新

在旧版页面右上角点击“检查更新”，发现 v0.8.3 后按提示确认。程序会按当前平台下载并校验更新包，保留本机配置、日志、运行数据和用户导入文件，替换后自动重启。
