# Xynigo Sourcing v0.17.1 任务历史与物流耗时测试版

v0.17.1 是内部测试通道补丁版本，补齐物流查询与买家号建环境任务的稳定标识、历史追踪和真实执行耗时，并收紧云端工作台的信息展示。

## 主要变化

- 修复终态物流批次仍残留“查询中”行的问题：失败、执行不确定和取消路径会统一把未完成行收口为可重查失败或已停止，历史旧数据也会在读取时安全归一化。
- 异常批量重查会包含终态批次中遗留的未完成行，但不会重复提交仍在执行中的环境；后续成功结果会覆盖旧异常，退款等正常业务终态保持不变。
- 每个物流查询批次新增稳定查询 ID；单行重查和异常批量重查继续关联原查询 ID，页面显示短 ID 并可复制完整 ID。
- 物流历史按最近更新时间倒序；重查开始、进度、完成、失败和取消都会让原批次置顶，首次查询时间保持不变。
- 新增逐环境真实执行耗时，平均值按所有实际进入执行且已完成的环境尝试计算；使用中跳过、取消和未执行行不计入。
- 物流进度统一展示已处理数、单环境平均耗时、本轮重查耗时和累计执行耗时；累计值不包含两轮任务之间的空闲时间。
- 新增环境创建历史，覆盖干跑预览、正式创建、失败重试和断点续跑，并按稳定任务 ID 汇总。
- 环境历史展示创建人、执行器、站点、HubStudio 分组、任务类型、计划/成功/恢复/失败数量、状态、实际执行耗时和最近更新时间。
- 环境历史逐账号明细只展示脱敏账号标签和无凭证执行信息。
- 云端“高级设置”仅回显桌面执行器配置；查询结果状态说明改为支持鼠标、键盘和触屏的帮助浮层。
- 停止物流批次时，尚未执行的环境明确标记为已停止，并继续排除在真实执行次数和平均耗时之外。

## 升级说明

- 云端数据库迁移到唯一 head `0029_operation_history_metrics`。
- 迁移会为环境创建运行回填逻辑根任务 ID，新增历史排序索引，并为物流查询结果增加真实执行标记和毫秒耗时字段。
- 云端服务与本地执行器需要同时升级到 v0.17.1，旧结果仍可查看，但升级前没有采集的逐环境耗时不会被推算。
- 部署时必须先备份 PostgreSQL，再执行 Alembic 迁移；共享测试只重建认证服务，不重启数据库容器。

## 测试边界

- 本地完整测试 658 项通过、3 项按平台条件跳过；云端 176 项全部通过。
- Windows 与 macOS 安装包继续使用内部 `test` 通道，尚未完成 Authenticode、Developer ID 签名与公证。
- 线上环境仍为共享隔离测试实例，不包含生产数据库、生产凭证或生产飞书数据。
