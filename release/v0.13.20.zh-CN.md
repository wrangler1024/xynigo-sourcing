# Xynigo Sourcing v0.13.20 物流查询与插件数据源协同测试版

v0.13.20 集中修复物流查询重查、截图、导出和运行状态问题，并完成采购助手插件的数据源管理收口。

## 主要变化

- 单条重查和异常重查作为原批次的子任务执行，页面、刷新恢复和 Excel 导出都保留整批结果及原始输入顺序。
- 本地执行器随查询进度上传脱敏轨迹截图到 24 小时短期云端缓存；查询进行中即可预览，完成后由云端合并导出。
- 查询页新增有效订单、已发货、未发货、打包中和待核对统计，并明确打包中属于未发货子集。
- 预检与准备阶段改为明显状态区，耗时超过 30 秒自动提示；查询期间禁用冲突导出。
- 查询结果字段支持当前页面配置显示/隐藏，偏好按飞书账号保存并跨电脑同步，接口可复用于后续页面。
- HubStudio 状态只采用所选执行器的本机实时探测结果；执行器补充浏览器内核检查和受审计修复流程。
- 采购助手插件不再修改数据源，成员默认、团队默认及环境绑定解析上下文由桌面客户端统一管理并安全回显。
- Windows 与 macOS 从同一 Git 基线同步构建发布。

## 测试边界

- 当前安装包仍按内部测试通道发布；平台签名状态以安装包元数据和发布清单为准。
