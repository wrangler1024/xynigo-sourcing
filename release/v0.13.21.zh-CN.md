# Xynigo Sourcing v0.13.21 建环境可靠性与真实干跑预览测试版

v0.13.21 重点修复大批量买家号建环境的受理、查重、续号和预览链路，并收口本轮物流查询及组织凭证改造。

## 主要变化

- 买家号建环境正式任务改为云端快速受理，所选本地执行器在后台异步执行，避免 120 秒等待造成页面误报失败而任务仍在运行。
- 云端新增租户级 Hub 环境库存缓存，以数据库事实源完成跨设备全局查重、断点恢复和并发安全续号；执行器继续对目标分组做最终本机核验。
- “干跑预览”改为真实下发到所选执行器，复用正式任务的解析、全局查重和续号规则；云端只保存、展示脱敏邮箱和计划环境名。
- 环境创建后的出口 IP 抽检严格执行配置数量；抽检数等于已完成环境数时验证全部环境。
- 物流查询补齐历史任务、关闭页面后恢复、轨迹截图预览、字段显示偏好、统计摘要及分级导出基础能力。
- 飞书企业应用凭证统一由超级管理员在云端加密配置，普通员工及本地执行器不再接收 App Secret。
- Windows 与 macOS 从同一 Git 基线同步构建发布。

## 升级说明

- 云端数据库将依次迁移到 `0025_hub_environment_inventory` 和 `0026_environment_dry_run`。
- 真实干跑预览与云端库存同步需要 v0.13.21 本地执行器；旧执行器会被能力门槛安全阻止，不会静默降级执行。

## 测试边界

- 当前安装包仍按内部测试通道发布；平台签名状态以安装包元数据和发布清单为准。
