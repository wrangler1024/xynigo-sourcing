# Xynigo Sourcing v0.13.13 Windows 原生防白屏测试版

v0.13.13 将 Windows 客户端调整为原生状态页优先显示，解决 WebView2 初始化自身阻塞时连网页恢复页也无法出现的问题。

## 主要变化

- Windows 窗口创建后立即显示原生状态页，不依赖 WebView2、显卡驱动或网页脚本。
- WebView2 在独立宿主区域中延迟初始化，不再直接覆盖整个主窗口。
- 只有 HTML 界面完成真实就绪握手后，客户端才从原生页切换到完整原型界面。
- WebView2 初始化阻塞、导航失败或连续重试失败时，原生界面始终保持可见和可操作。
- 原生页按静态原型的信息层级呈现状态横幅、云端通道、HubStudio、本机任务、执行器版本、设备与快捷操作。
- 原生页支持打开浏览器完整界面、本机设置、日志目录、重启执行器、在线更新和手动重试 WebView2。
- Windows 与 macOS 从同一 Git 基线同步构建发布。

## 视觉边界

- 信息架构、颜色、卡片顺序、状态和操作入口与静态原型对齐。
- Windows 原生控件的字体抗锯齿、圆角和阴影与 HTML/CSS 存在少量系统级像素差异。
