# Xynigo Sourcing v0.13.19 Windows 无闪烁启动修复测试版

v0.13.19 修复 Windows 桌面客户端启动和重试 WebView2 时短暂露出原生兼容状态页的问题。

## 主要变化

- Windows 主窗口默认保持隐藏，收到新版桌面页面的 `desktop-ready` 就绪握手后再显示。
- 正常启动、托盘唤醒和重试 WebView2 期间不再闪现旧版风格的原生兼容页。
- WebView2 连续三次加载失败时仍会自动展示原生兼容页，保留启动执行器、日志和重试入口。
- 用户关闭窗口后继续驻留系统托盘，不会因后续页面握手再次自动弹窗。
- 云端任务安全门槛提示补齐；物流查询继续要求本地执行器不低于 v0.13.18。
- Windows 与 macOS 从同一 Git 基线同步构建发布。
