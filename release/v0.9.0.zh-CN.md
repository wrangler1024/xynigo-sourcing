# Xynigo Sourcing v0.9.0

v0.9.0 升级买家号建环境后的飞书统一台账回写契约，补齐环境分组信息，并完善真实字段样式兼容和已完成批次的独立补写能力。

## 新功能与修复

- 统一台账新增“环境分组名”必需字段，API 创建、补全、幂等比对、写后回读和人工应急 TSV 均使用同一字段顺序。
- 同一 HubStudio 环境移动到其他分组时更新原台账记录；账号已绑定到不同环境时仍按冲突处理，不会因更换分组而重复插入。
- 飞书文本字段使用 Email 或 URL 显示样式时可通过字段预检；其他真实类型不匹配仍会阻止写入。
- “接码Key链接”按飞书原生 OpenAPI 的 URL 对象格式写入，修复错误码 `1254068`／`URLFieldConvFail`。
- HubStudio 已完成但执行时未勾选飞书回写的批次，可通过“补写本批次飞书台账”单独执行；补写前再次确认并执行只读冲突预检，不重跑任何 HubStudio 步骤。
- 完整台账模板同步加入“环境分组名”，并明确 API 写回/TSV 实际覆盖自“站点”至“绑定时间”的连续 13 列；“首次登录日期”仍为字段预检必需，但当前建环境 API 不写入。

## 升级前检查

- 现有飞书“买家号（统一）”目标表必须先增加文本字段“环境分组名”，再执行系统设置中的“重新验证连接与字段”。
- 企业自建应用须在多维表格高级权限中拥有目标表的记录读取、新增和更新权限。
- 首次正式回写前建议使用测试表完成一批脱敏样例验收，再切回生产台账目标。

## 安全与兼容性

- HubStudio 写入与飞书回写继续分开确认；补写台账也需要单独二次确认。
- 冲突、部分失败和写后回读不一致均不会被计为成功；失败行可再次仅重试飞书回写。
- App Secret、访问令牌、Base Token、Table ID、记录 ID、完整台账链接、密码和 Cookie 不通过公开配置接口或错误信息回显。
- 自动化测试只使用 FakeHub、FakeLark、`example.test` 和公开脱敏标识。
- Windows x86_64 与 macOS Apple Silicon 同步提供更新包；macOS Intel 不在维护范围。

## 在线更新

在旧版页面右上角点击“检查更新”，发现 v0.9.0 后按提示确认。程序会按当前平台下载并校验更新包，保留本机配置、日志、运行数据和用户导入文件，替换后自动重启。
