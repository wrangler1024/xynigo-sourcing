# Xynigo Sourcing v0.13.22 物流可靠性与效率分析测试版

v0.13.22 聚焦物流查询的批量可靠性、发货时效分析、历史审计和页面操作体验。

## 主要变化

- HubStudio Local API 短暂断连时，执行器会在安全边界内重试和恢复，避免一个环境的瞬时连接故障直接终止整个批次。
- 查询结果新增第一条物流轨迹时间、轨迹摘要，以及下单到首条轨迹的耗时，便于采购评估订单发货时效。
- 桌面客户端新增物流浏览器运行模式入口，可配置无头模式或可见调试模式；云端高级设置入口不再与查询站点、HubStudio 分组混排。
- 查询历史新增“查询用户”字段。管理员可查看并筛选团队记录，普通成员只可访问自己的批次；跨用户历史不允许直接重查。
- 下单时间和查询时间按“日期在上、时间在下”紧凑显示，同时保持现有查询结果行高不变。
- 运行环境侧栏支持点击外部区域或按 Esc 关闭；查询历史、字段设置和导出操作在任务执行前后保持固定位置。
- Windows 与 macOS 从同一 Git 基线同步构建发布。

## 升级说明

- 云端数据库将迁移到 `0027_logistics_first_tracking`，新增首条物流轨迹及发货时效字段。
- 新的首轨时效采集和断连恢复能力需要 v0.13.22 本地执行器；旧执行器不会获得本版新增采集能力。

## 测试边界

- 当前安装包仍按内部 test 通道发布，Windows Authenticode 与 macOS Developer ID 公证门槛仅在 stable 通道强制执行。
