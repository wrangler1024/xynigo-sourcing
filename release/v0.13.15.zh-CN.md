# Xynigo Sourcing v0.13.15 macOS 在线更新崩溃修复测试版

v0.13.15 修复 macOS 标准客户端点击“检查更新”或“更新”后意外退出的问题，并继续同步发布 Windows 客户端。

## 主要变化

- 修复原生客户端收到本地执行器成功响应后，在向 WebView 发送通知时触发 `SIGABRT` 的问题。
- 顶层通知字符串改用 Swift `JSONEncoder` 编码，避免 Objective-C `NSJSONSerialization` 抛出不可捕获异常。
- 保留下载、校验、安装和重启状态的实时显示。
- Windows 与 macOS 从同一 Git 基线同步构建发布，运行时版本保持一致。

## macOS 升级提示

- v0.13.12 至 v0.13.14 的 macOS 客户端本身包含此崩溃点。如果点击在线更新仍出现“意外退出”，请从云端“系统管理 → 本地执行器”下载 v0.13.15 标准安装包覆盖安装一次。
- 安装 v0.13.15 后，后续版本可继续使用客户端内在线更新。

## 测试边界

- 当前安装包仍未签名，仅用于内部测试。
