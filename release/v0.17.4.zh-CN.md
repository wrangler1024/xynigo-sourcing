# Xynigo Sourcing v0.17.4 缓存维护与采购数据源优化

v0.17.4 在桌面执行器中交付 HubStudio 安全缓存维护，并补齐采购助手个人速填表代配置、团队默认切换与界面说明。

## 主要变化

- 新增 HubStudio 缓存管理：自动识别常见安装与缓存位置，检测可清理大小，按网页资源、脚本与渲染、客户端界面三类选择清理。
- 清理前要求关闭全部环境并从托盘退出 HubStudio；清理期间暂停本机业务任务准入，目录状态变化或进程重新启动时停止处理。
- 清理严格限定在缓存白名单，保留 Cookie、LocalStorage、IndexedDB、扩展、下载文件、浏览器内核和账号登录数据。
- 超级管理员新增“为采购员新建个人表”能力，可在创建数据源时选择成员并直接设置其个人默认；普通采购员仍只能配置自己。
- 阻止同一张个人速填表重复归属给不同采购员。多人共用的数据源应登记为团队协作表。
- 采购员默认映射可明确选择“改用团队默认”；团队详情和操作提示同步说明团队默认不会自动覆盖个人默认。
- 采购助手插件配置窗口改为紧凑宽屏布局，减少右侧空白并保留窄屏自适应。

## 升级与验证说明

- 云端和 Windows/macOS 桌面执行器需配套升级到 v0.17.4，采购助手插件继续使用本地 v0.6.0 开发包重新加载验证。
- 数据库保持 `0030_logistics_auto_site`，本版本不新增迁移。
- 发布后需分别验证缓存检测与安全清理、管理员代建个人速填表、个人默认切换团队默认，以及插件数据源回读。
- Windows 与 macOS 安装包用于内部测试通道，沿用当前未签名状态；Windows 真机覆盖安装与缓存清理需在发布后完成验收。
