# Xynigo Sourcing v0.12.7 采购团队切换测试版

v0.12.7 面向当前采购团队从云端 Web 工作台下载安装本地执行器并开始正式切换测试，集中收口真实设备测试中发现的配对、钥匙串、下载入口和状态显示问题，并加入 HubStudio 原生适配器与采购助手本地服务。

## 新版本怎么使用

1. 在云端 Web 打开“系统管理 → 本地执行器”，默认下载 Windows 标准安装包；Mac 用户手动切换为 macOS Apple Silicon。
2. 下载前核对页面显示的文件名、大小和 SHA-256。标准包仍未使用平台可信签名，只限内部团队；按教程手动确认 Windows SmartScreen 或 macOS Gatekeeper 提示。
3. Windows 安装后打开 Xynigo 状态中心；macOS 从“应用程序”打开 Xynigo Sourcing，并保持执行器窗口运行。
4. 回到云端生成 5 分钟一次性配对码并一键配对。执行器即使已经启动，也会自动发现新凭证并开始心跳，不再要求为了配对重新启动。
5. 页面显示“本地执行器在线”后，核对 HubStudio Local API 状态，再按需读取或保存设备运行配置。
6. 标准包不可用时，可在下载卡片展开同版本绿色版回退入口；旧配置、日志、运行数据和导入文件不得删除。

## 新增测试功能

- 新增 HubStudio Local API 原生适配器：识别客户端、Local API、认证和协议兼容状态，支持有限端口发现、环境查找以及显式打开、关闭和批量控制。
- HubStudio Local API Key 只保存在本机安全存储中，不写入 `config.json`，也不会返回给 Web 页面或插件。
- 新增采购助手本地 API v2：插件可按订单、包裹、店铺或系统订单键搜索采购任务，并在精确命中后读取收件信息用于一键填写。
- 采购助手可通过受限本机桥接调用 HubStudio 环境查找、打开、关闭和批量控制；采购任务搜索与收件信息读取在 HubStudio 离线时仍可使用。
- 新增 ASCII 格式 `OK1` 系统订单键，云端数据库、导入流程和飞书采购协作表使用同一稳定标识；旧客户端 `orderKey` 继续兼容。

## 本次修复

- 修复“先启动执行器、后配对”时状态停在 `paired`、云端长期离线的问题。
- 设备凭证在单次运行期间复用，不再在每次长轮询前重复读取 macOS Keychain。
- 飞书应用凭证读取增加进程内缓存，避免连续弹出 Python 钥匙串授权。
- 标准包和绿色包均从系统内下载入口获取，不再把采购同事跳转到 GitHub。
- 团队下载默认选择 Windows；Mac 用户仍可手动切换。
- 顶部执行器与 HubStudio 状态采用一致样式，并在所有业务页面按真实心跳持续更新。
- 设备配置只保留本机运行参数，业务站点、分组和采购员分配不再固化到某台电脑。

## 安全与范围

- Windows/macOS 标准安装包仍是内部未签名测试包，必须核对 SHA-256，并按系统提示人工放行。
- `xynigo://` 只允许启动、唤醒和一次性配对，不承载业务命令或长期凭证。
- 云端设备通道当前只执行配置读取与保存；采购助手的 HubStudio 控制走本机受限桥接，真实下单、建环境和物流任务尚未接入云端调度。
- 本次是“云端 Web 作为统一入口 + 本地执行器作为设备连接”的团队切换测试，不代表生产环境或全部本机业务任务已经云化。
- 采购助手需要本地执行器和飞书采购协作表配置；本版接口已就绪，但插件本身仍按独立测试节奏交付。
- 绿色版和既有本地流程继续保留为业务兜底，不得同时运行两套执行器操作同一 HubStudio。
