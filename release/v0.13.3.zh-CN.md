# Xynigo Sourcing v0.13.3 安全撤销优化测试版

v0.13.3 收口买家号建环境的批次显示、出口 IP 错误语义和“停止并撤销”链路。该版本仅用于共享测试和 Windows/macOS 联合验收，不代表独立生产环境上线。

## 主要变化

- 新环境 Run 提交后立即清空上一批表格、摘要和 IP 结果；预检阶段只显示当前批“正在预检和准备”，不再残留墨西哥或其他历史批次数据。
- 出口 IP 检测保留稳定错误码与安全摘要，区分 HubStudio 未返回 IP、归属地失败、国家代码缺失、国家不匹配、浏览器内核缺失及 Local API 错误。
- 重复执行同一文件时，页面分别统计“本批新建”和“历史恢复”；同组已有环境明确标记为恢复，不再误认为重复写入。
- “安全停止”升级为“停止并撤销”：停止领取新行，等待正在写入的整行收尾，再销毁当前 Run 确认新建的环境。
- `recoveredExisting=true` 的历史环境不进入自动删除目标；销毁动作严格绑定本 Run 记录的环境编号和名称。
- 删除超时后精确回查 HubStudio：环境已不存在视为幂等成功，编号与名称不一致则失败关闭，最多自动重试三轮。

## 防止立即重复创建

- 云端新增“租户 + 买家号不可逆引用”Run 门禁，覆盖 `active → cleanup_pending → cleanup_failed/释放` 生命周期。
- 用户停止后立刻修改参数、重新上传同一文件，或从另一标签页/另一台执行器再次提交相同账号时，撤销完成前统一返回 `environment_cleanup_in_progress`。
- 全部确认删除后门禁自动释放，可使用同一原始文件和新参数创建新 Run。
- 删除失败、执行器失联或租约进入不确定状态时保持失败关闭；下一次完整文件 Run 会先执行 HubStudio 实时存在性预检，确认无旧环境后才允许写入。
- 0021 数据库迁移会把已有 `cleanupStatus=failed` 记录回填为持久化门禁，升级不会丢失待清理事实。

## 联合测试重点

1. 美国站上传后进入预检，确认批量进度不再显示上一批墨西哥环境。
2. 构造 HubStudio 未返回 IP、内核缺失和国家信息缺失，确认页面显示对应原因。
3. 对已存在环境的同一文件再次执行，确认显示“历史恢复”而不是“本批新建”。
4. 建环境执行中点击“停止并撤销”，确认已新建环境全部删除，历史恢复环境保留。
5. 撤销过程中立即重新提交相同账号，确认云端阻断；撤销成功后再次提交应正常受理。
6. 模拟删除超时或执行器失联，确认门禁保持且不会静默创建重复环境。

## 升级说明

- Windows 测试通道可在线更新到 v0.13.3，下载完成后仍需用户明确确认安装。
- macOS 使用 v0.13.3 标准安装包覆盖安装。
- 当前安装包未签名，仅限内部测试；安装前必须核对 SHA-256，并按内部教程确认系统安全提示。
