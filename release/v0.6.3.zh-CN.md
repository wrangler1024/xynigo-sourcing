# Xynigo Sourcing v0.6.3

v0.6.3 是订单及物流查询的紧急能力补丁，重点补齐 SHEIN 美国站，并保持墨西哥站查询兼容。

## 主要更新

- 查询页新增墨西哥站 / 美国站选择；选择标准采购分组时可自动切换对应站点。
- 支持 `us.shein.com` 的订单列表、订单详情和物流轨迹路由。
- 支持美国站 `Order NO.`、美元金额及 Shipped、Paid、Processing、Delivered、Refunding 等英文状态。
- 继续从详情页 SSR 数据提取物流单号、包裹号和承运商，并生成隐藏地址与商品区域的轨迹截图。
- 承运商优先读取轨迹页商业名称；已验证内部 SPX/GOFO 路由分别展示为 SpeedX/GOFO。
- 订单详情页新增风险验证识别；待提交证明材料的订单显示为“风险订单/待验证”，不再误报为普通 Paid 成功。
- 查询结果统计新增“风险订单”独立计数，并从“成功”中扣除，避免重复统计。
- 查询时间与 SSR 备用下单时间读取各 HubStudio 环境浏览器的真实当地时区，不再固定按墨西哥时间解释。
- 查询站点与标准环境名中的 MX/US 不一致时，在打开环境前阻止误查。
- 模块三新增本机采购分组与动态代理安全配置及执行前预检；代理链接不经页面或 API 回显。
- Windows 与 macOS Apple Silicon 同步提供更新包。

## 在线更新验收

在 v0.6.2 页面右上角点击“检查更新”，发现 v0.6.3 后点击更新提示；在自动置前的运行窗口输入 `Y`。程序应完成下载、SHA-256 校验、备份、替换与重启，并保留本机 `config.json`、日志、运行数据和用户导入文件。

更新后进入“物流订单查询”，选择“美国站 · us.shein.com”，使用有权查询的美国采购环境验证订单状态、物流单号和轨迹截图。未发货订单应显示业务状态并明确暂无物流；标准环境名与所选站点不一致时应在打开环境前被阻止。
