# Xynigo Sourcing v0.8.0

v0.8.0 是飞书多维表格 OpenAPI 直连功能版。买家号建环境完成后，可通过“小犀代采”企业自建应用回写统一买家号台账，不再要求同事电脑安装 `lark-cli`。

## 主要更新

- 系统设置移动到左侧功能栏，集中管理本机业务参数与飞书 OpenAPI 配置。
- App ID / App Secret 在当前电脑安全保存；页面明确显示是否已配置，但永不回显 Secret。
- 只需粘贴包含 `table=tbl...` 的飞书 `/base/` 或 `/wiki/` 完整链接，系统自动解析台账目标；支持确认后重新配置。
- 提供“买家号统一台账完整模板”下载，字段顺序、类型提示、日期样式和单选项与当前统一台账契约对齐。
- 建环境前只读扫描统一台账，以邮箱账号和号商购买单号执行双键查重；跨站命中、双键分裂、重复记录和状态冲突会在 HubStudio 写入前阻断。
- HubStudio 环境结果与飞书同步结果分层记录。飞书失败不会把环境标记为创建失败，也不会在重试时再次创建环境。
- 新增、补全和幂等确认均以写后回读为准；超时或回读不一致保留为“待重试”。
- 部分失败支持仅重试待同步行，已经确认的台账行和 HubStudio 步骤不会重复执行。
- 注册模块的已知 `record_id` 更新路径也改用共享 OpenAPI 客户端，并增加写后回读。
- Windows x86_64 与 macOS Apple Silicon 同步提供更新包；macOS Intel 不在维护范围。

## 安全与兼容性

- 飞书回写默认关闭，正式执行时与 HubStudio 写入分开二次确认。
- App Secret 不进入公开源码、`config.json`、日志或发行包；macOS 使用当前用户钥匙串，Windows 使用 CurrentUser DPAPI。
- Base Token、Table ID、完整台账链接、访问令牌和飞书记录 ID 不通过页面/API 回显。
- 密码、Cookie、接码 Key 只在当次任务内存和飞书请求短路径中使用；进度、异常和测试快照只返回脱敏摘要。
- 自动化验证仅使用 FakeLark、FakeHub 和 `example.test` 公开脱敏样例。本版本发布过程不执行真实飞书或 HubStudio 业务写入。
- 人工 TSV 仍保留为一次性应急路径，统一从“站点”列开始粘贴；API 是否成功只以写后回读结果为准。

## 配置提示

企业自建应用必须已获目标多维表格的访问权限，并具备读取字段/记录以及新增、更新记录所需权限。使用 Wiki 链接时，还需要 Wiki 节点只读权限和相应知识空间访问权。配置完成后先执行“只读检查统一台账字段”，再在建环境页面按需开启回写。

## 在线更新验收

在旧版页面右上角点击“检查更新”，发现 v0.8.0 后按提示确认。程序应完成平台选包、下载、SHA-256 校验、备份、替换与重启，并保留本机 `config.json`、日志、运行数据和用户导入文件。更新后页面标题与稳定版标识均应显示 v0.8.0。
