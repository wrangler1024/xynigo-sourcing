# Xynigo Sourcing v0.13.18 HubStudio 查询准入与熔断修复测试版

v0.13.18 修复 HubStudio 未启动或浏览器内核不可用时，云端仍显示可查询并继续执行整批物流任务的问题。

## 主要变化

- 正式物流查询启动前，使用一个符合站点条件且未占用的目标环境执行可逆的启动/关闭预检。
- 只有 HubStudio 返回有效调试端口后才创建本机查询任务；浏览器内核缺失会直接拒绝整批。
- 浏览器内核缺失、Local API 不可达、认证失败等系统级错误触发整批熔断，剩余环境不再继续启动。
- 运行时发现浏览器内核异常后，HubStudio 状态立即降级并在短期内覆盖表面正常的 `group/list` 心跳。
- 云端新增业务任务硬门槛：执行器必须在线，且 HubStudio 必须上报 `ready`。
- 前端补充“浏览器内核不可用”等明确错误提示，不再把系统故障显示成普通查询完成。
- 桌面客户端“本机任务”状态卡支持打开实时明细，展示任务类型、开始时间、运行时长和占用环境数量。
- 任务明细仅返回脱敏运行字段，不返回任务 ID、环境名称、订单号、账号或凭证。
- Windows 与 macOS 从同一 Git 基线同步构建发布。
