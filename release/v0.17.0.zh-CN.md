# Xynigo Sourcing v0.17.0 环境身份与任务恢复测试版

v0.17.0 是一次内部测试阶段的次版本升级，集中解决采购买家号环境命名冲突、云端环境缓存重复记录，以及本地执行器租约过期后任务长期卡在运行中的问题。

## 主要变化

- 新建绑定环境采用 `采购员代号-站点-YYMMDD-连续序号-四位短码` 三层命名；短码不包含容易混淆的 `0/O/1/I`，极端冲突时自动换码重试。
- 备用和测试环境同样带日期与稳定短码；同一批次的干跑、正式执行和断点续跑生成一致名称。
- 云端缓存优先使用 HubStudio 环境 UUID 和 `containerCode` 识别真实环境，名称仅用于显示与兼容历史数据。
- 完整环境快照按强身份合并记录，只清理已确认删除且没有真实身份的旧占位记录，保留活跃、预留和身份不确定的数据。
- 缓存同步在独立数据库保存点内执行；即使缓存数据异常，也不会污染任务完成回传事务。
- 执行器轮询领取任务前自动回收本机过期租约，避免任务已超时但设备仍被判定为忙碌。
- 对租约过期后迟到的有效完成结果进行受控接纳，恢复原任务而不是制造新的重复执行。
- 任务结果回传重试期间持续发送不领取新任务的心跳，云端可及时恢复租约，桌面端显示“任务结果回传重试中”。
- 已有旧格式环境名称继续兼容，无需批量重命名。

## 升级说明

- 云端数据库迁移 head 仍为 `0028_hub_environment_cache`，本版本不新增数据库迁移。
- 新环境命名、缓存身份对齐和租约恢复需要云端与 v0.17.0 本地执行器配套升级。
- 发布到共享测试环境后，已有过期运行任务会在执行器下一次轮询时自动恢复；排队任务随后可继续领取。
- 建议分别在 Windows 与 macOS 验证干跑、正式创建、任务完成回传、客户端在线更新和物流查询。

## 测试边界

- 当前安装包继续使用内部 `test` 通道；Windows Authenticode 与 macOS Developer ID 公证门槛仅在 `stable` 通道强制执行。
- 线上环境仍为共享隔离测试实例，不包含生产数据库、生产凭证或生产飞书数据。
