# Xynigo Sourcing v0.5.1

v0.5.1 是 Windows 与 macOS 同版本双端维护的首个稳定版。同一 GitHub Release 提供 Windows、macOS Apple Silicon 和 macOS Intel 绿色包。

## 主要更新

- macOS 绿色包内置运行时，不需要另外安装 Python。
- Windows 和 macOS 都在启动时检查 GitHub Releases 最新稳定版。
- 两端都支持中文更新说明、`Y` 更新、`N` 跳过、SHA-256 校验、更新前备份、失败回滚和自动重启。
- 继续保留 `config.json`、本地数据、日志和用户导入文件。
- 更新清单兼容 Windows v0.5.0，已安装的 Windows 版可直接在线更新。

## 首次使用

1. 按电脑系统与架构下载对应 ZIP。
2. 完整解压到普通文件夹，不要在压缩包预览窗口中运行。
3. Windows 双击 `启动.bat`；macOS 首次右键 `启动-Mac.command` 并选择“打开”。
4. 以后发现新版本时，输入 `Y` 更新或输入 `N` 跳过。

> 更新功能不会将本机配置、日志或业务数据上传到 GitHub。
