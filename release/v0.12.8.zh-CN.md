# Xynigo Sourcing v0.12.8 内部切换收口测试版

v0.12.8 当前 Windows 运行时修订将在线更新控制入口迁入执行器桌面状态中心。Web 工作台不再显示“检查更新/立即更新”，也不再通过云端 RPC 下发更新任务；macOS 资产保持不变。

## 升级方式

1. 从云端 Web“系统管理 → 本地执行器”下载对应平台的 v0.12.8 标准安装包。
2. 核对页面显示的文件名、大小和 SHA-256；当前仍是内部未签名测试包，需要人工确认 Windows/macOS 安全提示。
3. 已安装 v0.12.7 的电脑直接覆盖安装，不需要卸载，也不选择绿色包迁移。
4. 覆盖安装保留 `config.json`、日志、运行数据和设备配对；Windows 会切换到 v0.12.8 不可变运行时，Mac 保留用户应用数据目录。
5. 安装后确认状态中心显示执行器在线、HubStudio 状态正确，再执行真实物流或建环境任务。
6. 本次覆盖安装完成后，后续 Windows 更新统一在执行器桌面状态中心操作，不再从 Web 工作台触发。

## 本次收口能力

- 云端 Web 是团队统一入口；本机执行器通过 `workspace.rpc.v1` 执行物流查询、买家号解析/入库、账号注册、HubStudio 建环境、店铺/代理读取和文件导出。
- Windows 包包含定版状态中心、动态配对区、原生托盘菜单、运行时修订目录、旧执行器接管和桌面在线更新入口。
- 检查、确认、下载、SHA-256 校验、安装和重启均由本机执行器负责；有本机任务运行时拒绝升级。
- macOS 包随附可信 CA，最终冻结程序可以直接验证云端 TLS；设备与飞书凭证在进程内复用，减少钥匙串弹窗。
- HubStudio 回环请求强制不走系统代理，支持有限端口回退、分组读取和安全短任务排队；Windows 后台诊断不显示黑色控制台。
- 设备列表、配置、撤销和任务操作同时按组织与当前用户隔离；敏感任务正文加密保存，外部写入继续采用租约、幂等和不确定态。
- 买家号文件解析支持经过验证的混合登录 Cookie；失败重试后回读环境状态；MX/US 建环境参数完成全链路闭环。

## 安全与发布边界

- Windows 未做 Authenticode；macOS 未做 Developer ID Installer、公证与 stapling。稳定渠道仍不接受这些未签名资产。
- `xynigo://` 只负责启动、唤醒和一次性配对，不承载业务命令或长期凭证。
- 下载通过云端同域认证接口，服务器只提供审核过的固定资产并校验大小与 SHA-256。
- 本版只部署共享测试环境。生产服务器、正式数据库与正式飞书业务路由未上线。
- v0.12.7 的历史 hotfix 资产和标签保留用于审计与回滚，不覆盖、不删除、不移动。

## 重点验收

- Windows：从旧 v0.12.7 覆盖升级、运行时切换、状态中心/托盘启动、在线更新交接、无黑框、配置与配对保留。
- macOS：覆盖安装、TLS 心跳、HubStudio 分组和 RPC 执行。
- 业务：MX/US、单来源/混合 Cookie、物流查询、买家号解析与建环境回读。
