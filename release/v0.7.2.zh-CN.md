# Xynigo Sourcing v0.7.2

v0.7.2 是买家号建环境模块的紧急补丁，修复飞书台账直贴 TSV 与当前多维表格列结构不一致导致的字段错位。

## 主要更新

- MX 和 US 按各自当前默认 Grid View 输出独立列序，不再共用一套旧列序。
- 台账直贴 TSV 不再写入表头和旧「备注」列；文件打开后第一行就是数据。
- 为只读公式字段「购买日期」保留空占位，使 Cookie、号商单号、账号状态、绑定环境、环境序号、采购员和绑定时间进入正确列。
- 下载文件名显式标注站点、「无表头」和「从邮箱账号列开始」。
- WebUI 页内说明和二次确认均警告：只能从当前站点台账第一空行的「邮箱账号」列开始，不能从「账号ID」列开始；台账列序若有变动必须停止粘贴。
- 系统下载的号商入库 xlsx 模板仍强制带 `邮箱账号 / 密码 / 接码Key链接 / Cookie` 表头，不受本次去表头改动影响。
- Windows x86_64 与 macOS Apple Silicon 同步提供更新包。

## 在线更新验收

在旧版页面右上角点击「检查更新」，发现 v0.7.2 后按提示确认；程序应完成下载、SHA-256 校验、备份、替换与重启，并保留本机 `config.json`、日志、运行数据和用户导入文件。

更新后下载一份脱敏/FakeHub 生成的台账直贴 TSV，确认文件名含站点和「无表头_从邮箱账号列开始」，文件内第一行直接为数据且每行 11 列。不以发版验收为由执行未授权的 HubStudio 或飞书真实写入。

## 后续方向

本补丁仍保留人工 TSV 备用链路。下一功能版本将以飞书多维表格 API 直接回写为主线，减少含凭证文件的手工传递与粘贴。
