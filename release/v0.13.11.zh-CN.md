# Xynigo Sourcing v0.13.11 Windows 窗口渲染修复测试版

v0.13.11 修复部分 Windows 电脑升级 v0.13.10 后 WebView2 窗口整页空白的问题，并为桌面界面加载失败增加自动恢复能力。

## 主要变化

- Windows WebView2 使用新的稳定数据目录，隔离旧版本遗留或被锁定的浏览器缓存。
- Windows 默认启用软件渲染兼容参数，降低远程桌面、显卡驱动或 GPU 合成异常导致白屏的概率。
- 桌面页面加载完成后主动向原生启动器发送就绪握手。
- 未收到就绪握手时最多自动重试三次，每次带独立防缓存参数。
- 连续失败后显示恢复页，支持重新加载、在系统浏览器打开本机页面和打开日志目录。
- 后台执行器、设备配对和云端任务通道与 WebView2 界面解耦，界面异常不会中断执行器心跳。
- Windows 与 macOS 从同一 Git 基线同步构建和发布。

## 测试边界

- 当前候选安装包仍未签名，仅用于内部测试。
- v0.13.10 的白屏窗口仍可通过 Windows 系统托盘“检查更新”进入 v0.13.11 在线更新流程。
