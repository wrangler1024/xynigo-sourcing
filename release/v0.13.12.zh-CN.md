# Xynigo Sourcing v0.13.12 Mac 更新控制恢复测试版

v0.13.12 修复 Mac 原生客户端重新启动后仍连接旧执行器进程，导致状态正常但更新和重启请求被 403 拒绝的问题。

## 主要变化

- 客户端控制令牌以仅当前用户可读的 `0600` 权限保存在本机运行数据目录，客户端安全重启后可恢复同一执行器会话。
- 新增无副作用的本地控制握手，区分当前受控执行器与上一客户端会话留下的孤儿进程。
- 当前没有执行任务时，只在进程路径确认属于当前 Xynigo 安装后结束旧会话并启动新的受控执行器。
- 如果旧会话仍有任务运行，客户端不会强制中断，待任务完成后再恢复控制。
- 更新请求的 HTTP 状态与阶段写入脱敏状态中心日志，不记录令牌或业务数据。
- Windows 继续包含 v0.13.11 引入的 WebView2 白屏恢复修复；Windows 与 macOS 从同一 Git 基线同步构建发布。
