# Xynigo Sourcing v0.17.14

- 建环境任务中断后显示结果待核对，按已确认完成数量统计，不再把已创建但未完成绑号的环境误报为完成。
- 创建历史新增载入原批次和核对续跑：原创建人在原采购电脑重新上传原文件，保留原采购员分配及环境名，核对已有环境后继续完成。
- 恢复前重新读取 HubStudio 全量环境，已完成的不重复创建；环境身份冲突或绑号结果不明确时保留环境并提示人工核对。
- 任务受理、执行或结果回传期间阻止退出和重启；客户端重新打开时使用身份校验接管旧会话，状态无法确认时不强制结束执行器。

## 使用说明

1. 先更新云端服务，再在原采购电脑的 Xynigo 客户端检查更新，升级至 v0.17.14。
2. 使用原创建账号打开建环境模块，在创建历史中载入中断的原批次。
3. 选择原采购电脑，按原站点与分组上传原始 xlsx；混合 Cookie 或文件名冲突仍需明确确认。
4. 点击“核对并续跑原批次”，确认旧任务已经停止。已完成行保留；证据不足的已有环境会提示人工核对。
5. 续跑期间保持执行器和 HubStudio 运行。采购助手连接异常先使用插件“重新检测”。

## 发布范围

延续内部 test 更新通道与 GitHub Prerelease。本版无新增数据库迁移，Windows 和 macOS 按同一构建提交生成；安装包校验值已按实际产物固定。历史任务不会因升级自动重建，操作系统强制结束进程或断电仍可能中断任务。
