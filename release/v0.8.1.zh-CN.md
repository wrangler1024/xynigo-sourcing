# Xynigo Sourcing v0.8.1

v0.8.1 是买家号建环境的紧急解析兼容补丁，适配号商把账号邮箱从接码链接查询参数移动到 URL 路径末段的新交付格式。

## 修复内容

- 继续兼容旧 `orderNo`、`id + email` 和仅 `email` 查询参数格式。
- 新增“账号邮箱位于 URL 最后一个路径段”的交付格式，支持标准 URL 编码邮箱。
- 同一账号的 query-email 与 path-email 链接统一生成相同的稳定内部引用，避免号商只改变链接格式后绕过既有查重。
- URL 在提取任何号商身份前先校验 HTTP(S)、主机、user-info 和 fragment；旧 `orderNo` 只从解析后的查询参数读取。
- 路径格式继续严格校验链接邮箱与本行账号邮箱一致，并拒绝异常编码、路径与查询混用及歧义链接。

## 安全与兼容性

- xlsx 仍按第一张工作表固定四列解析，兼容有表头或无表头；密码、Cookie 和接码链接不会通过页面、错误或日志回显。
- 既有全 HubStudio 跨分组号商引用查重、飞书统一台账双键查重、预检和二次确认门槛保持不变。
- 自动化测试只使用 FakeHub、FakeLark、`example.test` 和合成 Cookie；发布过程不执行真实 HubStudio 或飞书业务写入。
- Windows x86_64 与 macOS Apple Silicon 同步提供更新包；macOS Intel 不在维护范围。

## 在线更新

在旧版页面右上角点击“检查更新”，发现 v0.8.1 后按提示确认。程序会按当前平台下载并校验补丁包，保留本机 `config.json`、日志、运行数据和用户导入文件，替换后自动重启。
