# Xynigo Sourcing v0.6.2

v0.6.2 是一个聚焦浏览器品牌图标与在线更新验收的补丁版本，不包含买家号建环境后端的新开发内容。

## 主要更新

- 浏览器标签页 Favicon 统一使用最终确认的 Xynigo X 图标，不再使用小犀图标。
- PNG、ICO、快捷图标和 Apple Touch Icon 入口统一使用根路径并指向 X 图标。
- ICO 补齐 16、24、32、48、64、128 和 256 像素尺寸，提高 Windows Chrome/Edge 标签页兼容性。
- 提升图标资源缓存版本，更新并重启后浏览器可重新请求正确图标。
- 保留 v0.6.1 的 WebUI 更新提示、控制台确认、SHA-256 校验、备份、回滚与自动重启机制。
- Windows 与 macOS Apple Silicon 同步提供更新包。

## 在线更新验收

在 v0.6.1 页面右上角点击“检查更新”，发现 v0.6.2 后点击更新提示；在自动置前的运行窗口输入 `Y`。程序应完成下载、SHA-256 校验、备份、替换与重启，并保留本机 `config.json`、日志、运行数据和用户导入文件。

> Favicon 的验收位置是浏览器标签页。Chrome/Edge 地址栏左侧可能显示浏览器自己的站点控制图标。重启后若标签页仍短暂显示旧图标，请关闭旧标签页并使用新打开的 v0.6.2 标签页确认；v0.6.2 已使用新的图标缓存键。
