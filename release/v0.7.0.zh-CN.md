# Xynigo Sourcing v0.7.0

v0.7.0 为买家号建环境模块（模块三）带来采购员名单与备用环境体系，同事端开箱零配置。

## 主要更新

- 采购员名单写死四人：新刚-XG / 志恒-ZH / 康德-KD / 宇航-YH；分配改为卡片点选，每卡自带「全给」按钮，默认均分给新刚/志恒/康德三人，均分余数顺位前者 +1。
- HUB 环境名统一英文代号：`{代号}-{站点}-{MMDD}-{NNN}`（如 `XG-MX-0819-001`），去掉「采购-」前缀；存量旧命名环境不改名、互不影响。
- 新增「备用·测试环境」模式：不绑买家号，只建环境并写固定备注「备用环境/测试环境」，单批上限 25，批末可下载结果清单 TSV；备用环境与绑号环境共享当日代号序号段自动续排。
- 建环境从串行改为并行执行（默认 5 并发，设置页可调 1-10），批量创建速度约提升至 3 倍以上。
- 内置默认动态代理提取链接，新机器开箱零配置；如需自定义可在设置页覆盖，清除即恢复内置默认。
- 采购分组下拉默认选中站点标准分组（墨西哥=希音墨西哥采购、美国=美国采购分组），并过滤店铺/后台类分组，列表更清爽；购买日期改原生日期控件，默认今天。
- 账号站点自动校验：按 Cookie 登录域（shein.com.mx / us.shein.com）识别账号国家，与所选站点冲突时在干跑预览与正式执行两道关口整批拒收，防拿错文件建错站。
- 收养防护：执行中发现同名环境备注非空（可能为其他机器的备用/已绑号环境）时拒绝收养并提示人工核对，防止跨机撞名错绑。
- 正式执行启动后进度条与计时即时刷新；进度获取失败不再静默。
- Windows 与 macOS Apple Silicon 同步提供更新包。

## 在线更新验收

在 v0.6.3 页面右上角点击「检查更新」，发现 v0.7.0 后按提示确认；程序应完成下载、SHA-256 校验、备份、替换与重启，并保留本机 `config.json`、日志、运行数据和用户导入文件。

更新后进入「买家号建环境」：应看到绑号/备用·测试两种模式切换、四张采购员卡片与英文代号命名预览；选择分组下拉只显示采购与买家号相关分组；备用模式建 1 个测试环境验证备注与结果清单下载。
