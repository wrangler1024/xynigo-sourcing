# Xynigo Sourcing v0.13.0 业务 Run 云端化测试版

v0.13.0 完成阶段2业务 Run 云端化，并修复 v0.12.12 现场测试收集的环境创建问题。该版本仅用于共享测试和 Windows/macOS 联合验收，不代表生产上线。

## 主要变化

- 环境创建和物流查询使用 PostgreSQL 持久化业务 Run，云端保存任务生命周期、增量进度、失败步骤和最后心跳。
- 刷新页面、切换模块或重新登录后，页面从云端恢复最近 Run，不再依赖执行器进程内状态重新查询整批结果。
- 买家号 xlsx 改用专用加密任务通道，由用户选中的本地执行器解析；云端不保存明文文件。
- 工作区快照统一恢复站点、采购分组、分组列表、预检和非敏感设备运行配置。
- 业务 Run 执行期间读取设备配置时显示最近只读快照，不与正式业务任务争抢执行器。
- 环境创建页面的预检、预览和正式执行统一使用页面当前选择的站点与采购分组。
- 进度阶段、每秒计时、安全停止、单行重试和失败项批量重试统一使用云端 Run 状态。

## v0.12.12 现场问题修复

1. 执行器忙碌时读取设备配置不再直接失败；有安全快照时显示只读值和更新时间。
2. 新建环境和账号注册不再硬编码 `coreVersion=148`，交给 HubStudio 选择当前默认可用内核。
3. HubStudio 返回 `-10007` 内核缺失时不重复请求，并提示安装或切换到可用内核。
4. 重新上传买家号文件后，执行按钮只依据当前站点、当前分组和本次解析计划判定。
5. 解析过程显示具体本地执行器及排队、领取、运行状态。
6. “均分”始终重新按新刚、志恒、康德三人分配，覆盖已有“全给”结果。

## 联合测试重点

1. Windows 与 macOS 各执行一次配置读取、文件解析和小批量建环境。
2. 环境创建运行中刷新、切页、退出登录并重新登录，核对 2 秒内恢复 Run、按钮和结果。
3. 选择正确站点和采购分组后重新上传文件，确认预检通过且正式执行按钮可用。
4. 创建 1–3 个脱敏测试环境，确认使用 HubStudio 可用内核并显示出口 IP 检测状态。
5. 先“全给新刚”，再点击“均分（默认三人）”，确认数量重新分配。
6. 模拟响应超时、安全停止、迟到成功和单行失败，确认不会重复提交外部写入。

## 升级说明

- Windows 可从 v0.12.9–v0.12.12 在线更新到 v0.13.0；更新仍需用户在客户端明确确认。
- macOS 使用 v0.13.0 标准安装包覆盖安装。
- 当前安装包未签名，仅限内部测试；安装前必须核对 SHA-256，并按内部教程确认系统安全提示。
