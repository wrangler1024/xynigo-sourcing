# Xynigo Sourcing v0.12.0 采购中心与环境创建优化全员测试版

v0.12.0 面向共享测试环境的全部现有用户，集中更新采购任务认领、采购执行工作台和 HubStudio 环境创建稳定性。该版本仍属于协同测试渠道，不代表生产环境开放。

## 采购中心

- 采购任务页作为团队公共待认领池，支持勾选多个采购单批量认领，并增加店铺、运营、站点与关键词筛选。
- 列表补充采购单金额、采购指导额、利润和利润率摘要；店铺与运营独立展示，为后续个人和团队业绩统计保留归属。
- 采购执行页只展示当前采购员已认领的采购单，采用宽屏列表和固定“详情 / 处理”操作布局。
- 一单一 SKU 一件且尚未开始采购时保留快捷下单入口；未分单、未开始的采购单可填写原因后退回公共任务池。
- 采购单详情展示收件信息、采购备注主/次规格和付款批次；物流单号、物流商、物流状态已预留在批次详情，等待后端回填能力开放。
- 为后续数据权限预留字段可见性策略，敏感字段必须由服务端角色策略裁剪，不能只依赖前端隐藏。

## 环境创建稳定性

- HubStudio Local API 请求增加全局错峰，避免多个环境创建线程同时冲击本地接口。
- 收到 `E010205` 请求频率限制后，所有工作线程共享 2/4/8 秒递增冷却，不再由单个线程立即重试。
- 环境已创建但后续查询受限时，重试会接管已创建环境继续执行，避免重复创建。

## 兼容与边界

- 继续连接共享测试环境；不会部署、连接或修改生产服务器。
- 本机更新只替换受管程序文件，继续保留 `config.json`、运行数据、日志和用户导入文件。
- 真实平台采购下单、店小秘审核、SHEIN 写入、飞书同步 Worker 和物流回填仍需配套后端状态机及单独授权。
- 业务操作日志与系统运行日志代码已进入发布源码，但共享测试云端尚未启用对应迁移和接口；本版本不会自行迁移云端数据库。

## 验证与回退

- 本地应用和云端认证服务完整自动化测试、公开源码安全审计以及 Windows/macOS 双平台包结构和 SHA-256 校验通过后发布。
- 如更新异常，可重新安装 v0.11.1 测试包；回退前保留配置、日志和运行数据。回退本机程序不会修改云端采购数据。
