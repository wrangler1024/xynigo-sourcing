# Xynigo Sourcing v0.12.9 号商接码链接兼容测试版

v0.12.9 兼容号商新增的邮箱接码链接格式，并修复文件校验失败后页面继续显示上一批统计的问题。本版从 v0.12.8 标签后的最新桌面更新基线继续，不回退执行器状态中心在线更新能力。

## 升级方式

1. 从云端 Web“系统管理 → 本地执行器”下载对应平台的 v0.12.9 标准安装包。
2. 核对页面显示的文件名、大小和 SHA-256；当前仍是内部未签名测试包，需要人工确认 Windows/macOS 安全提示。
3. 已安装 v0.12.8 的电脑直接覆盖安装，不需要卸载，也不选择绿色包迁移。
4. 覆盖安装保留 `config.json`、日志、运行数据和设备配对。
5. 安装后确认状态中心显示执行器在线、HubStudio 状态正确，再重新选择原号商 xlsx 校验。

## 本次修复

- 新增严格支持 `/api?type=html&mail=<邮箱>` 接码链接。
- 仅当 URL 为 HTTP(S)、没有用户信息或 fragment、路径为 `/api`、参数恰好为 `type + mail`、`type=html` 且 `mail` 与同行账号邮箱一致时接受。
- 新链接没有真实 `orderNo` 时，继续使用邮箱派生的稳定 SHA-256 引用；同一邮箱在既有邮箱链接格式与新格式之间共享同一查重引用。
- 重复参数、附加参数、邮箱不一致、错误 type、任意路径或不安全 URL 继续整批拒收。
- 文件重新选择或解析失败时清空旧统计，避免把上一次成功批次的账号数、Cookie 覆盖和单号数误认为当前结果。

## 既有能力保持

- 云端 Web 是统一入口；本机执行器通过 `workspace.rpc.v1` 执行物流查询、买家号解析/入库、账号注册、HubStudio 建环境、店铺/代理读取和文件导出。
- Windows 在线更新入口位于执行器桌面状态中心；Web 工作台不下发执行器更新任务。
- Windows/macOS 标准包和绿色包都包含本次修复；绿色包继续作为显式回退。
- 设备列表、配置、撤销和任务操作继续按组织与当前用户隔离；敏感任务正文加密保存，外部写入继续采用租约、幂等和不确定态。

## 安全与发布边界

- Windows 未做 Authenticode；macOS 未做 Developer ID Installer、公证与 stapling。稳定渠道仍不接受这些未签名资产。
- `xynigo://` 只负责启动、唤醒和一次性配对，不承载业务命令或长期凭证。
- 下载通过云端同域认证接口，服务器只提供审核过的固定资产并校验大小与 SHA-256。
- 本版只部署共享测试环境。生产服务器、正式数据库与正式飞书业务路由未上线。
- v0.12.8 的标签和历史资产保持不可变，用于审计与回滚。

## 重点验收

- 同一文件同时包含旧 `orderNo` 链接和新 `type=html + mail` 链接时全部解析通过。
- 新链接邮箱与同行账号不一致、带附加/重复参数或 type 非 html 时整批拒收。
- 解析失败后页面统计显示“本次校验未通过”，不保留上一批数字。
- Windows/macOS 覆盖安装后配置、设备配对、HubStudio 状态和 workspace RPC 保持正常。
