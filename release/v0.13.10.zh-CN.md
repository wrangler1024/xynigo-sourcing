# Xynigo Sourcing v0.13.10 配置脱敏回显测试版

v0.13.10 为本地执行器已配置参数增加安全识别摘要，解决重新配置时无法确认当前目标的问题。

## 主要变化

- 飞书数据源链接显示通用域名、固定掩码和 token 末四位，工作表标识仅显示末四位。
- HubStudio API Key 与飞书 App Secret 仅显示固定掩码和末四位。
- 飞书 App ID 沿用首尾掩码，自定义代理链接只显示协议、主机、端口及凭证占位符。
- 数据源详情与重新配置窗口都会显示“当前已配置”的脱敏摘要。
- 编辑输入框仍为空，不把掩码当成真实值；留空保持原配置，输入并校验新值后才执行替换。
- Windows 与 macOS 从同一 Git 基线同步构建和发布。

## 安全边界

- 完整 Spreadsheet Token、Sheet ID、API Key、App Secret、代理认证信息不会进入公开 API、DOM、日志或云端配置摘要。
- 当前候选安装包仍未签名，仅用于内部测试。
