# Xynigo Sourcing v0.13.17 Windows HubStudio 后台残留误报修复测试版

v0.13.17 修复 Windows 在 HubStudio 主窗口未启动时，因同名后台残留子进程仍存在而显示在线的问题。

## 主要变化

- Windows 不再只按 `Hubstudio` 进程名判断客户端是否启动。
- 至少一个 HubStudio 进程必须拥有非零 `MainWindowHandle`，才进入 Local API 可用性检查。
- 全部同名进程均无主窗口时直接上报“HubStudio 未启动”，不会被残留 Local API 监听误导。
- 本机检查使用隐藏 PowerShell 进程，不弹出控制台窗口，不读取进程参数或业务数据。
- 保留 v0.13.16 的执行设备刷新记忆和 HubStudio 三态展示。
- Windows 与 macOS 从同一 Git 基线同步构建发布。

## 测试边界

- 当前安装包仍未签名，仅用于内部测试。
