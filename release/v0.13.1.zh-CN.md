# Xynigo Sourcing v0.13.1 环境链路优化测试版

v0.13.1 合并环境创建页面与更新体验修复，以及环境快照索引和 HubStudio 精确查询优化。该版本仅用于共享测试和 Windows/macOS 联合验收，不代表生产上线。

## 主要变化

- 页面第一步先选择购买日期、建环境站点和 HubStudio 采购分组，再上传买家号文件、分配采购员并执行，避免先解析后发现站点或分组选错。
- 站点与采购分组优先从本地工作区快照读取，浏览器端使用 5 分钟缓存；切换选择时异步保存偏好，不再重复阻塞整页。
- 正式执行前仍按当前站点和分组实时预检，缓存不替代生产写入前的正确性校验。
- Windows 客户端在线更新显示下载进度条、百分比、已下载/总字节、速度、预计剩余时间，并区分下载、校验、解压、安装和重启阶段。
- 环境快照建立按容器编号和名称查询的索引，优先执行 HubStudio 精确查询，减少大批量环境下的全量 `env/list` 扫描。
- HubStudio 创建接口响应不确定时，先查找并认领已创建的目标环境，降低超时重试造成重复创建的风险。

## 保留能力

- 环境创建与物流查询继续使用可持久化云端业务 Run；刷新、切页或重新登录后可恢复任务状态、进度和结果。
- 买家号文件继续通过专用加密任务通道交由所选本地执行器解析，云端不保存明文文件。
- 安全停止、单行重试和失败项批量重试继续由云端 Run 状态驱动。
- 覆盖安装保留配置、日志、运行数据和设备配对；绿色包继续作为显式回退。

## 联合测试重点

1. 确认环境创建页面先选择日期、站点、采购分组，随后上传文件并分配采购员。
2. 连续切换美国/墨西哥站点及采购分组，确认缓存命中后无长时间页面卡顿，正式执行前仍能发现错误组合。
3. Windows 从旧版本确认在线更新，核对进度、速度、剩余时间和阶段提示连续变化。
4. 使用环境数量较多的 HubStudio 设备执行预览和小批量创建，核对精确查询耗时与结果。
5. 模拟创建接口超时后实际已成功，确认系统认领已有环境而不重复创建。
6. 刷新、切页或重新登录，确认云端 Run、按钮状态、进度与结果可以恢复。

## 升级说明

- Windows 可从已启用测试通道的版本在线更新到 v0.13.1；更新仍需用户在客户端明确确认。
- macOS 使用 v0.13.1 标准安装包覆盖安装。
- 当前安装包未签名，仅限内部测试；安装前必须核对 SHA-256，并按内部教程确认系统安全提示。
