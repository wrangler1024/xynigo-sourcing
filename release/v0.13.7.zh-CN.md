# Xynigo Sourcing v0.13.7 双端在线更新测试版

v0.13.7 首次为 Windows 与 macOS 标准桌面客户端提供统一的在线更新链路，为后续快速迭代建立基础能力。

## 主要变化

- Windows 与 macOS 均从已登录的 Xynigo 云端读取受控发布清单并下载对应平台安装包。
- 下载路径、文件名、平台、大小和 SHA-256 均在本机二次校验，校验失败不会启动安装。
- Windows 通过当前用户静默安装模式替换版本化运行时并自动重启。
- macOS 使用系统安装器完成 `/Applications` 授权与事务安装；检测到 `runtimeId` 更新后自动重启客户端。
- macOS 用户取消安装或 15 分钟内未完成时，客户端恢复启动原版本执行器。
- 稳定通道保持平台签名硬门槛；内部未签名候选包仅允许在 `test` 通道使用。
- 执行器兼容线上旧版能力协议，不再因 HTTP 422 一直显示“正在连接”。
- 两端继续统一使用 X 品牌图标。

## 升级说明

- 现有 macOS v0.13.6 尚未包含在线更新引导，需要最后一次手动覆盖安装 v0.13.7；此后可直接在客户端内更新。
- Windows v0.13.6 可在云端发布 v0.13.7 后直接使用在线更新，也可覆盖安装测试包。
- 更新保留 `config.json`、日志、运行数据、数据源注册表和设备配对。
- 当前候选安装包仍未签名，仅用于内部测试；安装前必须核对 SHA-256。
