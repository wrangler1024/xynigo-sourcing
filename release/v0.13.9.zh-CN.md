# Xynigo Sourcing v0.13.9 在线更新进度修复测试版

v0.13.9 修复在线更新已经执行但桌面页面没有反馈的问题，并将 Windows 历史版的更新状态和进度能力统一补齐到 macOS、Windows 共用界面。

## 主要变化

- 点击“继续更新”后立即进入可见的下载准备状态。
- 下载阶段显示百分比、已下载/总大小、实时速度和预计剩余时间。
- 检查清单、下载、校验、准备安装、系统安装器接管和自动重启均有独立状态提示。
- 更新忙态每 0.8 秒刷新，空闲时恢复 5 秒轮询。
- 请求失败、下载校验失败或系统安装器超时会显示错误原因和重试入口。
- Windows 和 macOS 共用同一套更新状态栏与进度条；平台安装方式仍分别使用 Windows 静默安装器和 macOS 系统安装器。
- Windows 与 macOS 必须从同一 Git 基线同步构建和发布；当前在 Mac 完成现场验收，Windows 包同时交付并保留 Windows 实机复验项。

## 升级说明

- 已安装 v0.13.7 或 v0.13.8 的客户端可直接在线升级。
- 更新保留现有配置、日志、运行数据、数据源注册表和设备配对。
- 当前候选安装包仍未签名，仅用于内部测试。
