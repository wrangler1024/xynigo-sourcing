# Xynigo Sourcing v0.7.3

v0.7.3 是买家号建环境模块的紧急兼容补丁，修复采购更换号商渠道后，部分新接码链接没有旧 `orderNo` 参数而导致整份 xlsx 无法解析的问题。

## 主要更新

- 保留既有十六进制 `orderNo` 链接的原有解析和查重行为。
- 严格兼容新号商的 `id + email` 与仅 `email` 两种接码链接结构。
- 新链接必须使用固定路径和精确参数集合；链接邮箱必须与该行账号邮箱一致。
- 对没有业务订单号的新链接生成不可逆、稳定的内部去重号，继续用于批内查重、HubStudio 跨分组查重和幂等恢复。
- 邮箱错配、重复参数、额外参数、未知路径或无效 id 仍会整批拒收，不做猜测式映射。
- Windows x86_64 与 macOS Apple Silicon 同步提供更新包。

## 安全与兼容性

- 真实号商文件、账号、密码、Cookie、接码链接和真实号商域名没有进入源码、测试、日志或发布包。
- 自动化测试只使用 `example.test` 合成链接和虚拟 Cookie。
- 本补丁不改变 HubStudio 正式写入的二次确认、跨分组查重、站点校验或凭证清理门槛。
- 第一工作表仍是唯一导入来源；号商文件中的其他工作表不会被合并，避免重复导入。

## 在线更新验收

在旧版页面右上角点击「检查更新」，发现 v0.7.3 后按提示确认。程序应完成下载、SHA-256 校验、备份、替换与重启，并保留本机 `config.json`、日志、运行数据和用户导入文件。

更新后重新选择新号商 xlsx，只执行载入解析，确认数量、Cookie 数和订单/内部去重号数量一致。正式创建环境前仍需核对 MX/US 站点、采购分组、采购员分配和全 HubStudio 查重结果。
