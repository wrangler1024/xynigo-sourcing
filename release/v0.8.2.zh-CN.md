# Xynigo Sourcing v0.8.2

v0.8.2 是飞书多维表格 OpenAPI 配置与买家号任务状态的稳定性补丁，重点解决 macOS 凭证保存卡住、当前连接目标不直观，以及开启飞书回写后页面容易被误判为未执行的问题。

## 修复与优化

- macOS 改用钥匙串非交互命令通道保存企业自建应用凭证，并增加 15 秒超时；App Secret 不进入进程参数、项目配置或日志。
- 保存飞书配置时持续显示“保存中”、成功或失败状态，明确区分本地文件预览与本机服务不可用。
- 配置或只读预检后通过 OpenAPI 获取当前多维表格与数据表名称；系统设置、建环境回写确认和注册回写确认均显示实际目标。
- 当前连接目标支持从系统页面以新标签页打开。跳转地址由后端使用已校验的域名和路由标识构造，公开配置 API 仍不回显 Base Token、Table ID 或完整原始链接。
- 买家号建环境与备用/测试环境新增提交中、后台执行、完成、部分失败和执行中断状态，提交期间锁定相关配置，避免重复操作。
- 开启飞书回写时先显示字段、双键和站点冲突只读预检状态；HubStudio 完成后单独显示飞书查重、写入和写后回读阶段。
- 最终状态同时统计 HubStudio 与飞书结果。飞书待重试、冲突或异常会显示“部分失败”，并给出仅重试飞书或人工核对冲突的对应提示。
- 连续获取不到进度时明确提示后台任务可能仍在执行，页面保持轮询，避免重复提交。

## 安全与兼容性

- 飞书回写仍默认关闭，HubStudio 写入与飞书写入继续分别二次确认。
- App Secret、访问令牌、Base Token、Table ID、飞书记录 ID、密码和 Cookie 不通过页面、公开配置接口或错误日志回显。
- 自动化测试只使用 FakeHub、FakeLark、`example.test` 和公开脱敏标识；发布过程不执行真实 HubStudio 或飞书业务写入。
- Windows x86_64 与 macOS Apple Silicon 同步提供更新包；macOS Intel 不在维护范围。

## 在线更新

在旧版页面右上角点击“检查更新”，发现 v0.8.2 后按提示确认。程序会按当前平台下载并校验更新包，保留本机 `config.json`、日志、运行数据和用户导入文件，替换后自动重启。
