# Xynigo Sourcing v0.10.0

v0.10.0 新增受控的跨模块安全并行能力。首次发布默认保持兼容串行；管理员可在系统设置中显式开启，并先在小批量测试环境灰度。

## 新功能

- 开启安全并行后，一个订单物流查询批次可以与一个买家号建环境批次同时运行。
- 订单物流查询也可以与一个备用/测试环境创建批次同时运行。
- 顶部状态区显示当前后台任务数量，并区分“兼容串行”和“安全并行”模式。
- 后台任务返回独立 `taskId`；本地任务状态接口只返回脱敏类型、耗时和资源数量。

## 安全边界

- 同一环境继续禁止双开。系统以环境名和 `containerCode` 建立进程级资源预占，冲突时在 HubStudio 写入或浏览器启动前返回 409。
- 买家号注册、两个物流查询批次、两个买家号建环境批次，以及买家号建环境与备用/测试环境创建继续互斥。
- 跨模块的 `browser/start` 与 `browser/stop` 控制请求统一串行提交；不同环境的浏览器会话仍可同时运行。
- HubStudio Local API 同时请求上限为 4；开启安全并行时，建环境工作线程自动封顶为 3。
- 后台任务运行期间，不允许修改 HubStudio 端口、查询并发、建环境并发或并行模式。
- HubStudio 写入与飞书写入的原有二次确认、查重、幂等恢复和写后回读规则全部保留。

## 当前限制

- 资源预占仅覆盖当前 Xynigo 本地进程，不能替代跨电脑、跨进程的中心任务锁。不同电脑同时操作同一 HubStudio 账号体系时仍须错开执行。
- 本版不开放注册任务并行，也不开放两个环境创建批次并行。
- 首次启用建议使用少量备用/测试环境，并保留“兼容串行”作为即时回退开关。

## 验证建议

1. 更新后先保持“兼容串行”，确认既有物流查询和建环境流程正常。
2. 在系统设置中开启安全并行。
3. 使用 5—10 个已有环境执行物流查询，同时创建 3—5 个备用/测试环境。
4. 确认没有同环境双开、重复创建、遗留浏览器窗口或持续的 `E010205`／`-10005` 错误。
5. 小批量稳定后再用于正式买家号建环境。

## 在线更新

在旧版页面右上角点击“检查更新”，发现 v0.10.0 后按提示确认。程序会按当前平台下载并校验更新包，保留本机配置、日志、运行数据和用户导入文件，替换后自动重启。
