# Xynigo Sourcing v0.14.0 物流首轨与设备审计可靠性测试版

v0.14.0 是一次测试阶段的次版本升级，集中解决物流首轨时效采集和查询执行器归属的真实性问题。

## 主要变化

- 首轨解析支持 SHEIN 真实轨迹组件的 `Sep 03 19:23` 等无年份时间格式，并使用订单下单时间补全年份。
- 跨年订单可自动识别下一年度的首条轨迹；早于下单时间或超出合理范围的时间不会计入时效。
- 本地执行器上传物流结果时附带设备安全存储中的设备身份证明，云端验证后记录真实执行器。
- 设备凭证只在请求时进入专用请求头，不写入业务结果、日志或本地持久化待同步队列。
- 云端会校验执行器所属用户和租户，身份不匹配时拒绝写入，避免任务错误归属。
- 旧版本地任务不进行不可靠的数据回填，历史页面明确显示“旧版本地任务（未记录设备）”。
- Windows 与 macOS 从同一 Git 基线同步构建发布。

## 升级说明

- 本版不新增数据库迁移，云端继续保持唯一 head `0027_logistics_first_tracking`。
- 首轨无年份解析和可信执行器归属需要升级到 v0.14.0 本地执行器。

## 测试边界

- 当前安装包仍按内部 test 通道发布，Windows Authenticode 与 macOS Developer ID 公证门槛仅在 stable 通道强制执行。
