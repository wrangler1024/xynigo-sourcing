# Xynigo Sourcing v0.17.16

修复采购明细已追加、随后报“采购链接写后回读失败”导致商品图片未开始导入的问题。

- 链接校验读取服务器实际值，要求完整显示文本及所有跳转地址一致，保留查询参数和规格片段。允许飞书自动识别出的 URL 类型，继续拒绝缩短标题、参数截断、目标不一致及公式。
- 缺少内嵌图片的已关联明细可读取原销售行的 SHEIN 图片网址。仅接受 HTTPS 官方图片域名，限制 5MB、超时及重定向；读取失败按明细记录，其他图片继续处理。未关联明细仍留空。
- 历史与同批次查重比较完整采购链接、规格、数量和指导价，人工采购备注可保持原样。相同历史采购订单整单跳过，真实采购内容变更继续阻断。
- 原批次续传不会重复追加已有明细，并跳过已有图片。页面链接计数表示本次补写数量，失败任务的 100% 不代表导入完成。

## 恢复操作

保留已经追加的数据，使用原导出文件及同一批次执行“续传未完成数据/图片”。如解析计划过期，重新上传同一个文件并校验原工作表；文件名与采购内容保持一致时，稳定批次不变。没有必要删除已导入的明细。

沿用现有内部 test 通道与 GitHub Prerelease，未调整登录策略、数据库结构或提单助手扩展。Windows 与 macOS 安装包按同一功能提交构建并固定实际校验值。
