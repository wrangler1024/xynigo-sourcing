# Xynigo Sourcing v0.12.3 云端工作台与完整买家号测试版

v0.12.3 汇总 v0.12.2 数据库事实源增量，并新增可脱离本机服务访问的云端 Web 工作台。云端与本机复用原版 UI；HubStudio、CDP 和 SHEIN 浏览器操作仍由本机执行器承担。

## 云端工作台

- 授权成员可以直接通过 HTTPS 登录云端工作台，使用已开放的采购、资源、日志和成员功能。
- 云端与本机共用同一份前端源码，保持原有布局、导航、页签、配色和 X 图标。
- 本机执行器离线不阻断云端页面；依赖 HubStudio/CDP 的本机操作会明确保持不可用。

## 完整数据

- 买家号库按权限展示完整账号、手机号、密码、Cookie、接码 Key/链接和全部迁移业务字段。
- 号商入库确认后将完整数据写入 PostgreSQL，并由 Outbox 异步镜像测试 Base。
- 旧表「买家号（统一）」仍不进入运行时查询链路。

## 凭证保护

- 数据库中的凭证使用独立部署密钥进行应用层认证加密。
- 只有同时具备买家号查看与敏感凭证查看权限的用户可以解密查询。
- Outbox、业务日志、系统日志、错误响应和仓库文件不保存真实凭证明文。

## 边界

测试 Base 按负责人明确授权保存可读凭证；该版本仍是团队线上协同测试版，不代表生产环境、真实自动下单或静默客户端升级已经开放。本机绿色包更新继续要求用户确认，并保留配置、日志和运行数据。
