# Xynigo Sourcing v0.12.3 完整买家号测试版

v0.12.3 在 PostgreSQL 买家号事实源基础上补齐完整账号、凭证和旧台账业务字段，并持续同步独立测试 Base。

## 完整数据

- 买家号库按权限展示完整账号、手机号、密码、Cookie、接码 Key/链接和全部迁移业务字段。
- 号商入库确认后将完整数据写入 PostgreSQL，并由 Outbox 异步镜像测试 Base。
- 旧表「买家号（统一）」仍不进入运行时查询链路。

## 凭证保护

- 数据库中的凭证使用独立部署密钥进行应用层认证加密。
- 只有同时具备买家号查看与敏感凭证查看权限的用户可以解密查询。
- Outbox、业务日志、系统日志、错误响应和仓库文件不保存真实凭证明文。

## 边界

测试 Base 按负责人明确授权保存可读凭证；该版本仍只用于共享测试环境，不代表生产环境或真实自动下单已开放。
