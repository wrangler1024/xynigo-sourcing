# v0.17.8 采购助手 CURP 支持

- 采购助手支持从个人速填表和团队协作表读取 CURP，仅在当前订单收件详情中返回，任务列表不包含证件值。
- 客户端数据源增加刷新表格字段，校验后保存最新读取范围，保留采购员默认值和环境映射。
- 导入模板增加可选 CURP，兼容旧文件；冲突值停止对应订单导入，重复导入保留人工补充值。
- 配合采购助手插件 v0.8.1，仅墨西哥站自动填写 CURP；墨西哥四位源邮编由插件补零，美国站继续使用八项地址字段和五位邮编。

继续发布到现有内部 test 更新通道，Windows 与 macOS 同步升级。升级后在客户端数据源中点击“刷新表格字段”，个人表范围为 A1:I，标准团队表范围为 A1:AR。需要跨设备共享范围更新时，由管理员发布组织配置，再由其他客户端拉取。

本版不增加数据库迁移，继续使用 0031_data_source_registry_sync。插件单独通过 HubStudio 团队扩展管理更新；执行器更新不会自动替换浏览器插件。
