# Xynigo Sourcing v0.15.0 执行器可靠性与环境库存缓存测试版

v0.15.0 是一次内部测试阶段的次版本升级，集中解决 HubStudio Local API 在大批量任务中的稳定性、建环境全局查重性能和跨设备恢复能力。

## 主要变化

- HubStudio Local API 统一使用进程级并发限制、请求错峰、断路退避和端口重发现，读取接口可在安全边界内恢复短暂断连。
- 环境创建和浏览器启动按操作幂等性分类；响应不确定的写入先回读外部状态，再决定接管或重试，避免重复创建。
- 买家号建环境干跑预览新增导入计划、读取库存和完成三个阶段，页面持续显示真实进度。
- 新增完整 HubStudio 环境快照缓存。首次或缓存过期时执行全量只读扫描，六小时内后续预览直接使用云端缓存。
- 云端缓存只保存环境标识、名称、分组以及号商单号哈希，不上传环境备注、接码链接、Cookie 或账号凭证。
- 正式建环境在缓存新鲜时使用云端库存完成全局查重和续排序号；缓存不可用时自动回退到 HubStudio 全量复核。
- 超级管理员可将失败环境行接管到另一台在线执行器；重新上传的原始 xlsx 只提取原批次失败账号，成功行不会重复创建。
- 物流查询新增墨西哥站砍单、支付待验证等真实状态识别，并继续支持只读连接已经打开的环境。
- 多台电脑可并发下载同一客户端安装包；服务端复用经过校验的文件摘要，避免并发下载互相阻塞。

## 升级说明

- 云端数据库迁移到唯一 head `0028_hub_environment_cache`，新增完整环境快照与缓存新鲜度表。
- Local API 可靠性、环境缓存快照上传和跨设备接管需要升级到 v0.15.0 本地执行器。
- 部署后的第一次建环境干跑会执行一次 HubStudio 全量扫描并初始化云端缓存，后续命中缓存时不再重复读取全部环境。

## 测试边界

- 当前安装包继续使用内部 `test` 通道；Windows Authenticode 与 macOS Developer ID 公证门槛仅在 `stable` 通道强制执行。
- 发布后需要在真实 Windows 与 macOS 各完成一次安装升级，并进行 100 个环境物流查询和买家号建环境现场验证。
