# Xynigo Sourcing v0.5.0

v0.5.0 是 Xynigo Sourcing 首个支持 Windows 绿色包在线更新的稳定版。首次仍需人工下载并完整解压本版绿色包；从此版开始，后续稳定版可在启动时检查并安装。

## 主要更新

- 启动时读取 GitHub Releases 最新稳定版，黑窗口显示当前版本、最新版本和中文更新介绍。
- 输入 `Y` 下载更新，输入 `N` 跳过；不需要 GitHub 账号，不需要安装 Git。
- 使用 Windows 系统默认网络配置，兼容 Clash Verge 系统代理和 TUN 模式；程序内不包含任何私有代理地址或账号信息。
- 下载完成后进行 SHA-256 校验，校验不通过时拒绝替换。
- 更新前备份当前程序，替换失败时自动回滚，成功后自动重启。
- 更新只管理程序目录，不覆盖、不上传 `config.json`、本地数据、日志和用户导入文件。
- 网络、GitHub 或更新检查失败时，继续启动当前版本。

## 查询与导出改进

- Excel 物流轨迹截图单元格在 v0.4.2 基础上再缩小 25%，图片仍锚定在对应行的单元格内。
- Web 设置可隐藏“环境名”和“出口 IP”，默认隐藏；Excel 导出始终保留两个字段。
- HubStudio 状态检测增加 12 秒缓存，页面只轮询当前模块；遇到 `E010205` 限流时保留上次状态，避免假离线。

## 首次使用

1. 下载 Windows 绿色包 ZIP。
2. 完整解压到普通文件夹，不要在压缩包预览窗口中运行。
3. 双击 `启动.bat`。
4. 黑窗口提示新版本时，输入 `Y` 更新或 `N` 跳过。

> 更新功能不会将本机配置、日志或业务数据上传到 GitHub。
