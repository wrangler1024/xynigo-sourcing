# Xynigo Sourcing v0.17.6 数据源读取与 Mac 粘贴修复

添加个人速填表或团队数据源时，旧的本机凭证检查会在请求云端前误报“飞书企业应用凭证尚未配置”。本版让数据源读取按实际连接方式完成认证，恢复云端组织应用下的工作表读取与字段校验。

- Windows 与 macOS 均修复数据源读取问题；员工电脑无需重新配置飞书 App ID 或 App Secret。
- Mac 增加标准“编辑”菜单，支持 ⌘V 粘贴、⌘C 复制、⌘X 剪切、⌘A 全选、⌘Z 撤销与 ⇧⌘Z 重做。
- 云端应用未配置、会话失效或文档无权限时，继续返回对应错误。

通过客户端“检查更新”安装新版。Mac 的菜单修复需要完整客户端更新，刷新页面不会生效。安装更新保留已有配置与业务数据；未保存的数据源请在更新后重新配置。

已使用脱敏回归验证云端工作表读取、字段校验、目标重新验证及异常处理，并完成原生 Mac 文本控件快捷键验证。数据库迁移版本保持 `0030_logistics_auto_site`。

继续发布到现有内部 `test` 通道，沿用当前安装包签名状态。
