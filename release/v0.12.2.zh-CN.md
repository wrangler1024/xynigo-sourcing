# Xynigo Sourcing v0.12.2 买家号数据库事实源测试版

v0.12.2 将测试版买家号业务与旧飞书「买家号（统一）」解耦，PostgreSQL 成为列表、查重、入库、占用和状态的唯一事实源。

## 买家号主链路

- 资源中心「买家号库」改为从共享 PostgreSQL 分页查询，不再从旧 Base 加载。
- 号商入库先使用账号哈希和单号哈希批量查重，再原子写入安全快照。
- 下单绑定、状态变更和并发占用继续由数据库事务和行锁裁决。

## 飞书 Base 镜像

- 新增买家号安全来源和 Base 同步状态字段，数据库事务同时产生 Outbox 事件。
- 云端 Worker 只将脱敏元数据幂等写入全新独立的「买家号安全同步测试表」。
- 落后版本事件会标记为 `superseded`，不能覆盖当前数据库状态。

## 旧表解耦与安全

- 测试版注册和建环境入口拒绝旧台账直写，停用手工 TSV 和旧表重试入口。
- 旧表只作一次性迁移源；默认 dry-run，且只读取白名单安全字段。
- 密码、Cookie、接码 Key/链接、完整账号和令牌不进入云端请求、PostgreSQL、新 Base 或日志。

## 边界

该版本仅用于共享测试环境。不代表真实平台自动下单、付款或生产环境已开放。
