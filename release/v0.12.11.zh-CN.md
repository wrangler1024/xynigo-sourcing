# Xynigo Sourcing v0.12.11 安全停止测试版

v0.12.11 在 v0.12.10 现场止血版本上新增建环境安全停止。该版本继续用于共享测试环境，不代表生产上线。

## 升级方式

1. 新刚电脑当前任务自然完成，或在安装 v0.12.11 后使用新按钮安全停止后续任务。
2. Windows 电脑可从状态中心由 v0.12.9 直接在线更新到 v0.12.11，无需先安装 v0.12.10。
3. macOS 当前仍需下载 v0.12.11 标准安装包后覆盖安装。
4. 覆盖安装会保留配置、日志、运行数据和设备配对；安装前仍应核对 SHA-256。
5. 当前安装包未签名，仅限内部测试，必须按内部教程人工确认系统安全提示。

## 安全停止语义

- 点击“安全停止”后，执行器立即停止领取尚未开始的环境行。
- 已经进入执行的行不会被强杀，会完整完成“建环境 → 导 Cookie → 绑账号 → 写备注 → 完成”后退出。
- 因此停止并非瞬时完成；最多仍有当前实际并发数的环境行需要收尾。
- 停止请求可以重复发送，不会重复创建停止任务，也不会提前释放本地任务占用。
- 停止期间不再执行新的出口 IP 验证，减少额外 HubStudio 活动。

## 续跑方式

- 买家号建环境：重新选择同一原始 xlsx，并保持站点、购买日期和采购员分配不变，系统按内容指纹读取脱敏断点，只执行未完成行。
- 备用/测试环境：按相同采购员、数量、类型和日期重新提交，系统按环境名称续排和现有环境幂等发现继续处理。
- 页面会把结果拆分为“完成 / 已停止 / 失败”，已停止不再混入失败统计。

## 对应现场问题

- 解决新刚电脑执行建环境任务时无法主动停止的问题。
- 避免用关闭执行器、结束进程或断开 HubStudio 的方式硬停任务，从而降低环境已建但账号未绑定、备注未写入的半成品风险。
- 为更新安装提供可控退出路径：先安全停止并等待页面显示“已安全停止”，再关闭执行器并安装新版本。

## 验收重点

- 并发设为 5 时发起安全停止，最多仅允许已经开始的 5 行继续完整收尾，其他排队行显示“已安全停止，未开始”。
- 页面停止过程中保持任务运行态，当前行收尾完成后才解除任务占用。
- 安全停止后不再出现新的建环境、Cookie、绑号、备注或 IP 验证调用。
- 买家号任务重新上传同一文件后只续跑未完成行，不重复执行已完成行。
- Windows v0.12.9 可直接在线更新到 v0.12.11，配置和配对保持不变。
