# Xynigo Sourcing v0.17.17

已提交采购单支持同组织多账号修订，主管或其他具备对应提单权限的运营可以在店小秘当前订单页面读取原采购明细并提交修改。

- 原提交人与首次提交时间保持不变，最近修改人与实际操作审计使用当前登录身份。
- 修改请求携带读取时的采购单版本号；其他窗口或账号已经更新时返回版本冲突，重新读取核对后才能提交。相同内容重试不增加版本。
- 已认领、已拆分或进入采购执行的单仍不能直接修改。插件未提交草稿保留原访问限制，跨组织订单不可读取，不新增工作台、订单列表或采购执行权限。
- 请求中的版本号不写入业务明细、不改变历史内容指纹，也不进入 XYP2 备注。

## 更新方式

先更新云端，再更新提单助手至 v0.12.8，刷新店小秘页面并重新打开采购明细。修改已提交单需要新版插件携带读取版本；旧版首次提单与相同内容重试继续兼容。

本版使用现有用户、修改人和审计字段，无新增数据库迁移，登录策略保持不变。沿用现有 test 通道与 GitHub Prerelease。
