# 售后订单与环境提示展示优化

状态：代码完成，未部署。基线 `dc9a1cd`，分支 `codex/after-sale-row-display`。

环境直提返回真实订单后，旧页面仍固定在每组订单前展示环境进度行，单订单环境因此看起来有两条订单。现在优先展示订单明细：环境正常结束、已返回订单全部终态且数量不低于环境已报告计数时，收起冗余环境行。

- 一单一条明细，多单各自展示；环境序号、商品、退款凭证及原因保留。
- 环境仍在处理、失败、停止、待核对、带错误信息或没有明细时，保留环境提示。
- 环境报告计数超过已返回明细数量时保留提示，避免掩盖回传不完整。
- 筛选使用全部关联明细判断是否收尾；筛选未显示订单但匹配环境状态时仍保留环境提示。
- 本次提交和历史详情共用渲染规则。只调整展示，不改变订单数据、数量统计、导出、回访或补提范围。

实际验证：真实环境/订单表格 fixture 通过；环境列表、售后反馈、任务生命周期及 Web 接线专项共 **93 passed**。覆盖正常单单/多单、跳过、处理中、异常、明细不足、筛选及旧空结果。云端 Web 与两份原型同步，重复生成无漂移；公开安全审计与 diff 格式检查通过。没有操作真实平台或部署服务。
