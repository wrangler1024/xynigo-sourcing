# XYP2解析器

入口：小犀助手 → XYP2解析器。沿用 `assistant.access` 权限，可在本机或云端使用；云端解析无需启用飞书协作导入或配置目标表。

粘贴一个采购单的店小秘完整客服备注，点击“解析采购清单”。工具使用与导入分单相同的 XYP2 解析器，展示站点、币种、来源 SKU、主规格、次规格、采购数量、指导单价和精准采购链接。指导价合计按单价乘数量求和，不计入运费、税费、凑单金额，也不代表实际付款。未提供的可选字段显示“未提供”，编码及原价、优惠比例位于折叠详情。

- 复制采购清单：中文文本，适合发给采购人员。
- 复制采购链接：每行一个精准链接。
- 复制到协同表：无表头的五列表格文本，顺序为“采购链接、主规格、次规格、需求数量、采购指导价”。从标准协同表“采购链接”列的预留起始明细行粘贴；数量和价格为数值，不附带币种文字。

协同表复制用于填写已有订单的预留明细行，不能创建完整分单记录。完整分单仍使用采购中心的导入分单功能。备注中的商品名称、图片、销售订单号、包裹号及收件信息不在当前 XYP2 标准字段中，工具不补造。

输入最多 20,000 字符。损坏或冲突备注不产生可复制结果；相同内容重复时仅解析一份并提示。修改、清空备注或解析失败会清除旧结果；过期请求返回时不恢复旧清单。剪贴板不可用时提供选中的文本供手动复制，表格文本会处理公式前缀和分隔符。

接口为 `POST /api/assistant/xyp2/parse`（本机）、`POST /v1/assistant/xyp2/parse`（云端），请求为 `{"remark":"含 XYP2 的备注"}`。接口只返回解析结果，不创建导入计划、采购单或飞书记录，不保存原始备注到业务表或审计详情。输入内容仅保留在当前页面内存中，不写浏览器持久存储。

回归覆盖：`tests/test_xyp2_parser.py`、`tests/fixtures/xyp2_parser_ui.cjs`、`cloud/auth-service/tests/test_xyp2_parser.py`。所有测试使用合成数据。
