# 退款单匹配 422 修复

v0.18.6 的按环境回访入口缺少 JSON Content-Type。浏览器发送字符串请求体时默认使用 text/plain，匹配接口在请求体验证阶段返回 422；带 JSON 请求头的接口验证未覆盖这个浏览器边界。

本次修复在匹配请求显式设置 application/json；公共错误转换保留服务端字符串 detail，让匹配上限等具体原因显示在状态卡片。未放宽云端校验、租户鉴权或确认后才发起任务的边界。

回归直接调用正式前端处理函数与 cloudFetchJson，用标准 Request 验证实际请求头、CSRF、凭证模式及参数，不再替换 cloudFetchJson。该测试在旧代码复现 text/plain 失败，修复后通过，并覆盖失败不派发、取消不派发与完整信息模式。共享 Web 输出已同步。

这是 v0.18.6 云端页面修复；现有安装包、更新目录和不可变 v0.18.6 标签保持原发布资产，桌面执行器无需升级。云端应用切换需同时更新页面和启动时计算的 CSP，按部署手册备份与排空后执行。实际部署提交、校验和回退材料记录在私有发布记录。
