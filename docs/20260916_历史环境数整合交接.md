## 功能与口径

提交历史批次列表在“执行器”和“提交”之间增加“环境数”。云端按该批次已有结果行中的环境序号去重，不按成功状态过滤；同环境多单只计一个环境，无结果行时为 0。结果逐步回传时环境数会增加。它不是计划环境数，也不是成功环境数；“提交”仍保留请求订单数，不能要求二者始终同步增长。

列表使用本页批次 ID 一次聚合，详情 API 的 batch.environmentCount 复用同一口径；批次 ID 来自已有租户范围校验。无数据库迁移，不改变执行、并发、退款提交或回访流程。
