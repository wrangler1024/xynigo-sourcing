# Xynigo 系统运行日志接口（P1）

日期：2026-08-26

状态：云端认证服务的结构化运行/错误日志、独立数据库表、只读 API、本机安全代理和 Web 列表/详情已在本地完成，尚未部署测试或生产环境。本机执行器、HubStudio/CDP、飞书同步 Worker 的日志采集尚未接入。

## 架构边界

系统日志使用独立的 `system_log_events` 表和 `SystemLogService`，不写入业务审计表 `audit_events`。当前采集云端认证服务的 HTTP 请求完成与未处理异常，查询系统日志本身以及 `/healthz`、`/readyz` 探针不产生日志。

每条日志包含：

- `tenantId`、安全主体 ID/姓名快照；
- `system_runtime` / `system_error` 分类；
- `info` / `warning` / `error` / `critical` 级别；
- 服务、组件、环境、事件类型和安全消息；
- HTTP 方法、路由模板、状态码和耗时；
- 异常类型、稳定错误码和 SHA-256 错误指纹；
- 来源、客户端版本、`requestId`、`traceId`；
- 发生时间和到期时间；
- 经过统一递归脱敏且有深度、数量、长度上限的 `details`。

不保存 URL 查询串、请求正文、响应正文、异常消息、堆栈正文、客户端 IP 或外部服务原始响应。未匹配到后端路由模板时只记录 `/unmatched`，避免把用户输入的路径内容写入日志。

## 采集与结果口径

- HTTP `2xx/3xx`：`system_runtime + info`；
- HTTP `4xx`：`system_runtime + warning`，错误码为 `http_{status}`；
- HTTP `5xx`：`system_error + error`；
- 未处理异常：`system_error + error`，只记录异常类名与 `unhandled_exception`，不记录异常消息和堆栈；
- `POST/PUT/PATCH/DELETE`、所有 `4xx/5xx` 始终采集；
- 成功的 `GET/HEAD/OPTIONS` 按 `XYNIGO_AUTH_SYSTEM_LOG_RUNTIME_SAMPLE_RATE` 确定性采样，默认 `1.0`；相同 traceId 的采样结果稳定。

日志写入使用独立数据库会话。即使业务事务回滚，系统错误事实仍可保存；反过来，日志写入失败只写进程标准错误，不改变原业务响应。

## 数据保留与容量

- 默认保留期：30 天，由 `XYNIGO_AUTH_SYSTEM_LOG_RETENTION_DAYS` 配置，范围 1–365 天；
- 默认每租户上限：100,000 条，由 `XYNIGO_AUTH_SYSTEM_LOG_MAX_ROWS_PER_TENANT` 配置，范围 1,000–10,000,000 条；
- 每个进程至多每小时执行一次内部清理：先删除过期记录，再按时间删除超过租户容量上限的最旧记录；
- 业务 API 不提供创建、编辑、删除或清理接口，业务用户只能只读查询。

## 权限与租户隔离

- 新权限码：`system.runtime_log.read`；内置管理员和超级管理员由服务端目录自动获得，自定义主管角色可单独授权；
- 云端接口与本机代理都执行该权限，前端同时按权限隐藏入口；
- 所有查询固定当前会话 `tenant_id`，请求不能指定或切换租户；
- 其他租户或租户范围外详情统一返回 `404 system_log_not_found`；
- 认证前或无法识别租户的全局运行日志可被内部保留，但租户 API 不展示，避免跨租户暴露。

## 接口

| 用途 | Web 同源接口 | 云端接口 |
|---|---|---|
| 系统日志列表 | `GET /api/system-logs` | `GET /v1/system-logs` |
| 系统日志详情 | `GET /api/system-logs/{systemLogId}` | `GET /v1/system-logs/{systemLogId}` |

列表筛选：

| 参数 | 说明 |
|---|---|
| `startTime` / `endTime` | ISO-8601 时间范围 |
| `category` | `system_runtime` 或 `system_error` |
| `level` | `info`、`warning`、`error`、`critical` |
| `service` / `component` | 精确匹配服务与组件 |
| `eventType` | 事件类型关键词 |
| `statusCode` | HTTP 100–599 |
| `requestId` | 同时匹配 requestId 和 traceId |
| `keyword` | 匹配安全消息、事件类型、路由模板、错误码或指纹 |
| `page` / `pageSize` | 每页最多 200 条 |

本机代理只允许列表和 UUID 详情的 GET 请求；拒绝外部 URL、路径穿越和写方法。云端 Bearer 会话继续只保存在本机安全存储。

## 前端入口

入口为“系统管理 → 系统运行日志”。页面包含筛选、倒序列表、分页和详情；详情展示安全主体、HTTP 摘要、异常类型/错误码、错误指纹、requestId/traceId、到期时间和脱敏详情，不展示原始堆栈或请求内容。
