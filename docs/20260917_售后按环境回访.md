# 采购售后：按环境序号回访

基线 `56b5213`（v0.18.5）。本地实现，尚未部署。

退款跟踪默认“按环境序号”，输入支持空格、中英文逗号/分号、换行，重复环境按首次出现去重。点击“回访指定单”先匹配本租户历史记录，列出各环境订单及退款单、无记录和缺少退款号的原因；确认后按输入环境顺序只读回访，取消不创建任务。可切换原“按退款单（完整信息）”三字段方式，切换不清空输入。

匹配跨提交批次和操作人，同时合并旧主退款单字段、多包裹退款数组及已有跟踪记录。退款单归属冲突时排除并标注原因；终态退款单仍允许明确回访。没有系统记录不代表平台没有退款，平台手工退款但系统未记录时仍需完整三字段；本功能不登录平台枚举未知退款单。

每次最多300个环境、500个退款单；最多查询5000条身份记录，不读取截图或退款账户字段。超限整体拒绝，提示缩小范围或从历史选择批次，不静默截断。匹配接口不创建任务、不改写历史凭证，确认后沿用现有任务载荷与执行器能力。

验证使用合成数据，覆盖跨批次、多包裹、去重保序、租户隔离、跟踪身份冲突、缺失字段、无记录、上限、鉴权和CSRF；确认匹配前后任务数和提交凭证不变，并验证确认后执行器领取的实际载荷。新增云端匹配测试3项通过，相关主仓专项94项通过。浏览器以正式样式和实际交互函数配合合成响应验证取消、确认、未匹配原因和布局，输入框与按钮均为44px，无横向溢出。

未操作真实订单或发起真实回访。发布需配套更新云端匹配接口及共享Web；无数据库迁移、无新执行器能力、无插件变化。
