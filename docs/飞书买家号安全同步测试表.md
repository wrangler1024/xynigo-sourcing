## 权限与安全边界

- 本测试 Base 已按用户明确授权保存买家号完整凭证；只向实际采购协作成员开放，不作为公开或生产台账。
- 飞书应用 Secret、数据库加密密钥、访问令牌、会话和代理凭证不写入本表。
- 完整账号、密码、Cookie 和接码资料不得进入仓库、日志、错误信息、截图或自动化测试夹具；验收只输出数量和错误码。
- 账号引用由 Xynigo 对原始账号生成稳定引用，用于幂等和数据库关联。
- PostgreSQL 是资源占用、下单流程和并发裁决的事实源；飞书表不承担锁和唯一任务队列。
- 共享测试服务和自动同步 Worker 已部署；旧表 320 条记录经一次性完整迁移进入 PostgreSQL，再由 outbox 镜像到本表，不属于 Base 直连或双向同步。邮箱和链接列使用重新创建的纯文本字段，避免 Email/URL 内部格式包装；320 条凭证与业务字段已按稳定账号引用逐字段比对，差异为 0。验收用的合成权限检查记录已删除，表内只保留真实迁移/业务镜像。
