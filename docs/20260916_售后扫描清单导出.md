# 售后扫描清单导出

② 可申请清单新增“导出清单 Excel”。导出当前扫描任务已返回的全部行，不受勾选影响、不重新扫描；运行中可导出部分结果。无结果及下载期间禁用按钮，下载失败后恢复。

列为环境序号、买家号环境、订单号、商品图链接、售后类型、送达时间、金额（MXN）、可退包裹、物流号、状态、备注。复用页面快照顺序和状态，完整保留错误原因；编号按文本、金额和包裹数按数值保存，字符串不执行为 Excel 公式，带冻结表头及筛选。

接口：`GET /v1/after-sale/scan/{task_id}/export`，要求 `assistant.access`，按当前租户与扫描任务类型隔离；未知任务返回 404。返回 XLSX，包含 Content-Disposition、X-Xynigo-Row-Count，并记录导出审计。

验证：前端与相关回归 113 项通过，新增下载失败及任务切换行为测试通过；扫描端到端与导出专项 12 项通过，覆盖运行中导出、未登录、未知任务、长编号、公式字面量、数值零、状态及行顺序。独立评审无必须改。
