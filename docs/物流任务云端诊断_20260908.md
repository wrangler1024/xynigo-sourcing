# 物流任务云端诊断

版本：v0.17.9。云端与采购电脑执行器均升级后，新任务开始上报诊断；不改变环境关闭策略，不自动重跑历史任务。

## 使用方法

进入云端工作台“系统日志”，在“关键词 / 查询 ID”中粘贴查询 ID，即可查看该查询及关联重查的 HTTP 记录。也可使用单次执行 ID 或执行器任务 ID 缩小范围。日志详情展示三个 ID、客户端版本、具体上报拒绝原因及期望/实际行数。

关闭等待记录会标为警告；结束汇总计数与任务范围不符也会标为警告。HTTP 422 保留业务错误码，例如 `executor_progress_snapshot_invalid`，并细分 `row_count_exceeds_task`、`environment_outside_task`、`diagnostics_schema_or_scope_invalid` 等原因。

研发排查可调用只读接口：

```text
GET /v1/operation-runs/logistics-query/{run_id}/diagnostics?page=1&pageSize=50
GET /v1/system-logs?queryId={root_query_id}
GET /v1/system-logs?runId={run_id}&statusCode=422
GET /v1/system-logs?taskId={executor_task_id}
```

诊断接口需 `system.runtime_log.read` 权限，严格限定当前租户。返回单次执行的状态、异常环境、最新关闭诊断、执行事件时间线、HTTP 日志及关联重查清单。列表各自返回 total、page、pageSize，最多每页 200 项；按相同 page 翻页，各列表独立判断是否还有数据。`executor.currentVersion` 是设备当前登记版本，历史请求执行版本以对应 HTTP 日志 `clientVersion` 为准。

## 采购电脑上传内容

云端派发的新物流任务携带 `diagnosticsVersion=1`。新版执行器才在进度快照中加入 diagnostics；旧执行器忽略这个可选参数。新版执行器面对旧云端不发送新增字段。

关闭诊断字段包括：环境序号、最后已知生命周期状态、是否确认关闭、关闭请求是否发出、调用关闭与查询状态的次数、关闭确认循环耗时，以及首次错误的操作/内部错误码/HubStudio 返回码。另保留最后一次关闭错误码和状态查询错误码，防止后续轮询错误覆盖首次故障。没有错误码时保留空值，不猜测错误原因。

`elapsedMs` 是关闭确认循环的耗时，不包含后续其他环境等待该关闭完成的全部时间。`state` 为最后成功取得的生命周期状态；状态查询失败时应同时查看 `statusErrorCode`。后续状态查询确认 closed/absent 后更新 confirmed。最多保留 20 条关闭检查，优先保留未确认项，每轮查询重新初始化。

诊断不上传 HubStudio 原始文案、请求头、请求正文、账号、Cookie、代理 URL、调试端口、浏览器页面或截图。服务端使用禁止额外字段的严格模型，限定错误码格式、计数范围和环境归属。异常行的既有 errorSummary 经过统一日志脱敏后展示。

## 持久化与兼容

- HTTP 关联与拒绝日志沿用 `system_log_events`，使用独立数据库事务，业务进度被拒绝并回滚后仍保留日志。
- 最新已接收诊断写入任务 request_summary 的 runtimeDiagnostics 和 runtimeDiagnosticsAt。不会把被拒绝的诊断当成有效状态。
- 不增加数据库表或迁移；日志继续使用当前保留策略，默认 30 天、每租户最多 100,000 条，先触及的限制可能缩短可查范围。最新任务诊断随任务记录保留。
- 旧任务不会补造原来未上报的错误码；诊断接口明确返回 diagnosticsAvailable=false 和缺失说明。历史 HTTP 日志没有关联字段时，不能通过新增 ID 筛选追溯匹配，仍需旧事件和访问日志。
- 单行重查的进度、截图及结束统计仅使用本次任务的环境，避免将整个历史结果集上报给单行任务。
- 若物流行进度持续被服务器以协议校验错误拒绝，先允许本地工作和清理完成，再以 executor_progress_rejected 结束；不在浏览器工作途中中断清理。截图单独上报失败仍沿用原有重试方式。
- 新云端对旧执行器的矛盾结束计数继续受理，但记录明确警告，避免让旧执行器陷入无法结束的循环。

## 验证

云端新增测试覆盖：进度事务回滚后诊断留存、查询/任务 ID 筛选、关闭首次错误留存、成功行关闭警告可见、恶意字段排除、异设备/跨租户隔离、未授权拒绝、请求模型校验失败、旧执行器兼容和分页。

执行器新增测试覆盖：只上传允许的字段、首次关闭错误和原始码、60 秒关闭超时、后续确认关闭、缓冲区上限和重置、单行重查排除其他环境与截图、协议版本协商、持续 422 后完成本地清理再明确报告失败。

以上均使用合成数据，不连接真实 HubStudio 或业务平台。
