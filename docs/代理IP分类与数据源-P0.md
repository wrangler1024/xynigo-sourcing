## 数据来源与库存口径

- 711 动态住宅代理在创建采购环境时通过已配置的动态提取 API 获取。API 链接属于敏感配置，不进入资源中心响应、页面、日志或导出；动态端点不作为固定库存逐条展示，也不计入固定代理资产总量。
- Webshare 静态数据中心 IP 的资产元数据来自飞书 Base「Webshare 资产同步数据」，占用关系来自飞书普通表格「Webshare IP 总表」。普通表格不可读时，占用统一显示“占用待授权”，不得推断为未使用。
- 静态住宅 IP 当前只有业务分类，没有已确认供应商、资产数据源或使用场景。页面展示“尚未接入资产台账”，不得伪造 0 条库存或演示资产。
- HubStudio Local API 只参与店铺环境只读对账，不是代理供应商数据源。

## 本地接口契约

`GET /api/resources/proxies` 在原有 `stats`、`rows`、`sources` 基础上增加：

- `typeCatalog[]`：始终返回三类已确认的业务分类及供应商、获取方式、使用场景、接入要求和库存口径。
- `rows[].proxyTypeCode`、`rows[].proxyType`：固定资产所属代理类型。
- `rows[].usageScenarioCode`、`rows[].usageScenario`：当前使用场景。
- `rows[].acquisitionModeCode`、`rows[].acquisitionMode`：获取方式。
- `rows[].accessRequirement`：不含真实 IP 或凭证的接入要求说明。
- `rows[].healthCheckSupported`：是否支持当前 Webshare 固定资产本机检测链路。

当前本机健康检测只支持 Webshare 静态数据中心 IP。711 动态住宅代理由采购环境创建流程按需提取，不能误走 Webshare 固定资产凭证读取接口；静态住宅 IP 在数据源与检测方式确认前同样不可检测。

## 安全与写入边界

- 本次仅增加分类、只读响应、筛选、展示和脱敏导出字段，没有新增数据库、飞书或代理供应商写接口。
- 普通列表继续跳过代理账号和密码列；检测任务只在明确选择 Webshare 固定资产后临时加载凭证。
- 页面只显示“白名单需包含本机出口 IP”的要求，不读取或展示当前真实出口 IP。
- 当前变更只在本地源码完成，未重启 8767、未部署共享测试环境、未调用真实 711/Webshare 接口。
