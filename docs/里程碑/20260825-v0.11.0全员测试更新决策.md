# v0.11.0 全员测试更新决策

日期：2026-08-25

## 决策

当前 Xynigo 测试用户只有一至两名，不再设置分批灰度。全部现有测试用户统一更新到 Xynigo Sourcing v0.11.0，并同步更新运营采购助手插件到 v0.11.0。

该决定只适用于共享测试环境，不改变生产隔离决策，也不把 v0.11.0 标记为生产稳定版。后续新增成员仍需完成飞书准入、最小权限角色分配和管理员批准。

## 更新方式

旧版在线更新器只读取 GitHub `releases/latest`。为兼容现有 v0.10.0 绿色包，已将 v0.11.0 以“全员测试版”标题发布为 latest Release，更新清单和包内渠道仍为 `test`。现有用户采用逐台受控在线更新：

1. 确认用户没有正在执行物流查询、注册或环境创建任务。
2. 在页面右上角点击“检查更新”，确认显示 v0.11.0 后进入运行窗口输入 `Y`；不要手工删除旧绿色包目录。
3. 更新器下载对应操作系统的 v0.11.0 `test` 渠道绿色包，完成 SHA-256 校验、旧程序备份、受管文件替换和自动重启；`config.json`、查询日志和运行数据保持不变，替换失败自动回滚。
4. 启动后确认页面标题和首页标识均为 v0.11.0 测试候选版，并验证飞书登录、权限、HubStudio 连接及原本地执行器入口。
5. 在浏览器扩展管理页加载或更新运营采购助手 v0.11.0，重新完成 Xynigo 本机配对。
6. 只做登录、列表和页面读取验收；采购认领、分单保存、真实下单、店小秘审核和飞书 Base 写入仍按各自授权边界执行。

## 回退

- 绿色包更新失败时恢复逐台更新前的旧程序目录，保留用户配置和业务数据。
- 插件异常时停用 v0.11.0 扩展并恢复上一测试包。
- 云端测试服务异常时只回滚测试服务器应用，不影响用户旧版绿色包和生产环境。
