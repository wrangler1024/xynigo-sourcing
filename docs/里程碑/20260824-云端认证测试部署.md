# 20260824 云端认证测试部署

## 结论

Xynigo 云端认证服务已在腾讯轻量服务器形成可访问、可恢复的隔离测试实例。测试地址为 `https://xynigo.samforo.icu`，本地采购服务和现有外部服务没有切换到该实例。

## 已验证

- Docker Compose 构建成功，PostgreSQL、一次性迁移容器和认证服务按依赖顺序启动。
- `/healthz`、`/readyz` 均通过 HTTPS 返回 200；未登录访问 `/v1/auth/me` 返回 401。
- 飞书登录入口 `/v1/auth/feishu/start` 返回授权跳转，state 与 PKCE 参数正常生成。
- PostgreSQL 迁移版本为 `0001_identity_foundation`，public schema 共 10 张表。
- PostgreSQL 不发布宿主机端口；认证服务只绑定 `127.0.0.1:8080`。
- Nginx 提供 HTTP 到 HTTPS 重定向、TLS 1.2/1.3、HSTS 和基础安全响应头。
- Let's Encrypt 证书当前有效期至 2026-11-22，系统已有自动续期任务。
- root-only 数据库备份能够恢复到临时数据库，表数和迁移版本一致；临时数据库已删除。
- PostgreSQL 与认证容器重启后能够恢复就绪，迁移与表结构保持不变。

## 当前阻塞

飞书应用 `samforo-cli` 的安全设置尚未添加以下精确回调 URL：

```text
https://xynigo.samforo.icu/v1/auth/feishu/callback
```

真实授权页因此返回 `20029 Invalid redirect URL`。该配置保存后，还需继续验证超级管理员首次登录、会话 Cookie、`/v1/auth/me` 权限摘要、退出撤销、数据库用户/会话/审计记录以及再次重启后的数据持久化。

## 回滚与备份

- 服务器部署目录：`/opt/xynigo-auth-test`。
- HTTP 阶段 Nginx 配置备份：`/opt/xynigo-auth-test/backups/nginx/xynigo.samforo.icu.http-pre-tls-20260824.conf`。
- 首次数据库备份：`/opt/xynigo-auth-test/backups/postgres/pre-login-20260824.dump`，权限为 `root:root 0600`。
- 回滚测试实例时只停止 `xynigo-auth` Compose 项目并恢复专用 Nginx 站点配置，不操作现有 n8n、HubStudio 或本地采购服务。

## 已知限制

- 当前是单机测试实例，没有高可用。
- 数据库备份仍在同机，尚未建立异机副本、保留周期和失败告警。
- 服务器访问 PyPI 较慢，首次镜像构建耗时较长；依赖未变化时可复用已缓存镜像层。
- 成员审批、角色授权、会话批量撤销和系统管理页面尚未实现。
