## 本次能力

- 云端 Web 固定提供“系统管理 → 本地执行器”和顶部连接状态双入口，下载安装、启动、配对、设备列表和配置读写位于同一页面。
- 5 分钟一次性配对码只用于交换设备身份；长期凭证进入 macOS Keychain 或 Windows CurrentUser DPAPI，数据库只保存摘要。
- 本地执行器主动通过 HTTPS 长轮询连接云端，云端以真实心跳判断在线；只消费配对码而没有首次心跳时不能显示在线。
- `0015_executor_channel_p1` 新增 `local_executors`、`executor_pairing_codes`、`executor_tasks` 和 `executor_task_events` 四张表，支持任务幂等、45 秒租约、续租、取消、脱敏事件和不确定结果。
- 本版设备通道只开放 `config.read.v1` 和 `config.write.v1`。查物流、创建环境和下单等真实业务任务仍走既有本地操作方式，尚未通过新通道下发。
- “查物流与建环境安全并行”配置可从云端读取和保存；开启后只允许两个模块跨模块并行，同一环境仍互斥。
