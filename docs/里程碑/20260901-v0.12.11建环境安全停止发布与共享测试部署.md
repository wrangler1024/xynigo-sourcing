# v0.12.11 建环境安全停止发布与共享测试部署

范围：买家号建环境、备用/测试环境、本地执行器、云端 Workspace RPC、双平台内部测试包、共享测试云端

结论：协作式安全停止已完成开发、三轮 CI、双平台发布和共享测试部署；没有移动或覆盖 `v0.12.10`。该版本仍是内部共享测试 prerelease，不代表生产上线。

## 安全停止设计

- 每个建环境 Job 在受理时创建独立 `threading.Event`，停止接口只设置事件，不杀线程、不关闭 HubStudio 进程。
- 每个 worker 只在领取一整行之前检查事件。已经进入买家号五步链路的行必须完整执行“建环境 → 导 Cookie → 绑账号 → 写备注 → 完成”；备用/测试环境已经进入执行的行也会完成建环境和备注。
- 并发为 N 时，停止后最多仍有 N 行需要收尾。排队行改为 `stopped`，不再进入任何 HubStudio 写调用。
- 停止请求幂等；本地任务占用直到当前并发行真正结束后才释放。停止期间不进行新的出口 IP 验证。
- 买家号停止行进入既有脱敏断点文件，文件不保存邮箱原文、密码、Cookie 或接码链接；重新上传同一文件并保持站点、日期和分配不变即可续跑。
- 页面新增“安全停止”，区分完成、已停止和失败，并明确显示当前最多仍需收尾的实际并发数。
- 云端 Workspace RPC 白名单新增 `POST /api/envbatch/stop` 与 `POST /api/envbatch/backup/stop`，继续使用 `resource.environment.create` 权限。

## 现场升级边界

1. 新刚当前 v0.12.9 没有安全停止接口，正在执行的任务必须先自然完成，不能通过关闭执行器或强杀 HubStudio 来“试用”新功能。
2. 任务结束后，Windows 可从 v0.12.9 直接在线更新到 v0.12.11，不需要先安装 v0.12.10。
3. 更新后先确认状态中心为 v0.12.11、云端在线、HubStudio ready，再用小批量脱敏测试账号验证安全停止。
4. 点击停止后必须等页面显示“已安全停止”；最多仍有当前实际并发数的行会完整收尾。
5. 续跑买家号任务时重新选择同一 xlsx，保持站点、日期和采购员分配不变；不得对结果不确定的旧任务盲目重新提交。
