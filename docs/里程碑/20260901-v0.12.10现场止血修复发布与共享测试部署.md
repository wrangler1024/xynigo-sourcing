# v0.12.10 现场止血修复发布与共享测试部署

日期：2026-09-01

范围：Web 会话、本地执行器在线状态、云端工作区 RPC、物流查询、建环境并发、HubStudio 只读加载、Windows 状态中心、双平台测试包、共享测试云端

结论：P0 止血代码已发布并部署到共享测试；两台现场 active 执行器仍为 v0.12.9，必须覆盖安装 v0.12.10 后，本机侧修复才完整生效。该版本不是生产稳定版。

## 核心根因

### 长任务期间执行器误报离线

执行器通过 25 秒长轮询领取任务，领取后主轮询线程同步执行本机 RPC。长任务期间主轮询暂停，但租约线程仍每 15 秒调用云端续租。旧云端 `renew_lease` 只延长任务租约，没有刷新 `local_executors.last_seen_at`；设备在线窗口为 60 秒，因此仍在工作的执行器会被 Web 判为离线。页面继续轮询时，设备状态、任务状态和 HubStudio 状态便出现反复跳动。

修复后，任务开始、租约续期、进度上报和完成都更新设备在线时间。租约、幂等和任务事实仍保留在 PostgreSQL，不用状态文案代替任务状态机。

### 其他放大因素

- Web Cookie 与数据库会话均固定 8 小时，没有活动续期；切回页面后会被迫重新登录。
- 查询按钮没有提交阶段锁；查询线程启动后才设置 `running`，首个进度快照可能误读为空闲。
- 云端和本机慢写调用分别只有 45 秒和 30 秒等待，HubStudio 全量预检稍慢即出现“云端失败、本机仍继续”的不确定窗口。
- `safeParallelTasks` 把建环境 worker 静默限制为 3，与用户配置 5 不一致。
- 物流查询使用可见 HubStudio 浏览器启动；分组与环境列表重复直读 Local API。
- Windows 托盘每 2 秒读取状态，旧本机状态接口可能同步触发 HubStudio 探测；700 毫秒读取超时又会把一次抖动直接显示为执行器未运行。

## 止血改动

- Web 会话保持 8 小时空闲期，活动页面每 15 分钟触发滑动续期；增加 7 天绝对期限，管理员撤销和账号停用仍立即生效。
- 本机执行器通道前两次失败写入 `reconnecting`，连续第三次才进入 `offline/error`；成功轮询立即清零失败计数。
- Windows 状态中心把读取超时提高到 2 秒，并在最近状态 15 秒内保留前两次失败快照。
- `/executor-status.json` 只返回最近一次 HubStudio 能力快照，不在托盘读取时同步访问 Local API。
- 云端 Workspace RPC 的 POST 请求携带 8–128 字符幂等键；查询、买家号建环境和备用环境在响应中断后复用同一个键。
- 查询提交阶段立即锁定按钮；查询编排器在后台读取环境前同步发布 `running=true` 和待查询行。
- 查询、买家号解析/入库、建环境等慢路径的本机等待提高到 120 秒；页面慢提交等待同步提高到 120 秒，并在失败后继续短时核对进度。
- 物流查询的 HubStudio `browser_start` 使用 `headless=True`。
- `envCreateWorkers` 直接决定建环境 worker 数，预检返回并显示 `configuredWorkers/effectiveWorkers`。
- HubStudio 分组列表缓存 30 秒，分组环境序号缓存 5 秒，缓存返回深拷贝并在重连时失效。

## 对应现场问题

| 现场问题 | 本轮止血 |
|---|---|
| 1 登录一段时间后失效 | 活动滑动续期、15 分钟保活、7 天绝对期限 |
| 2 执行器中断/未执行与状态跳动 | 任务续租刷新在线时间、通道与托盘三次防抖、状态接口非阻塞 |
| 3 买家号解析偶发失败 | 长任务在线时间修复、慢 RPC 120 秒、POST 幂等 |
| 4 切回系统重新登录、进度重取卡顿 | 会话续期、进度竞态与短时持续核对；跨刷新恢复仍待业务 Run |
| 5 解析变慢 | 减少状态探测争用并延长慢解析等待；文件直传/云端 Run 后续处理 |
| 6 配置 5 实际 3 | 移除静默 3 worker 上限，显示实际并发 |
| 7 建环境提交慢、超时后重复提示 | 提交锁、幂等键、120 秒等待、响应中断后核对进度 |
| 8 查询需多次点击、弹窗、结果需强刷 | 查询单飞、同步运行态、无头启动、持续进度读取 |
| 9 Hub 分组加载慢 | 分组 30 秒、环境序号 5 秒只读缓存；本机状态不再占用 Hub API |

## 现场后续顺序

1. 两台采购电脑分别覆盖安装 v0.12.10 标准包，不卸载旧版，不清除配置或配对。
2. 先确认状态中心显示 v0.12.10、云端在线、HubStudio 已连接，再做一个只读分组加载和一个单环境物流查询。
3. 验证物流查询不弹可见 HubStudio 窗口、结果自动显示；临时断网一次时显示正在重连，不立即离线。
4. 配置建环境并发 5，确认预检显示实际并发 5；只在明确授权的测试账号上执行一批小样本。
5. 不自动重跑此前响应中断、结果不确定的建环境或查询任务；先按现有进度和 HubStudio 实际状态核对。
