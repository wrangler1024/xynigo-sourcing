# v0.11.1 成员登录闭环

日期：2026-08-25

## 里程碑结论

新刚、志恒已在各自采购电脑安装 Xynigo Sourcing v0.11.1，完成“小犀代采”飞书授权并成功进入 Xynigo 工作台。至此，“成员新增/审批 → 角色分配 → 绿色包安装 → 飞书授权 → 本机安全会话 → 工作台登录”的真实多成员链路完成验收。

本里程碑完成的是共享测试环境中的成员准入和登录闭环，不代表 Xynigo 全项目、生产环境或真实采购执行已经完成。成员停用与会话即时撤销、最小权限采购员角色、跨租户拒绝、真实下单、飞书同步 Worker 和生产部署仍按后续任务单独验收。

## 故障与修复

v0.11.0 在飞书回调成功后仍可能回到登录页。根因不是飞书回调、成员审批、Windows DPAPI 或浏览器弹窗权限，而是未认证页面仍每 1.5 秒请求受保护的 `/api/tasks`；该请求返回 401 后触发通用工作区锁定逻辑，并清除了飞书登录轮询定时器。

v0.11.1 完成以下修复：

- 未认证期间不启动采购任务状态轮询，避免 401 中断登录流程。
- 本地服务仅向页面暴露安全布尔值 `loginPending`，页面刷新后可恢复尚未过期的登录轮询。
- 同一未过期登录请求会被复用，避免重复创建飞书 OAuth 请求。
- 暂时性云端不可达保留待完成请求；明确终止错误、过期或无效响应会清理待登录状态。
- 云端会话仍只保存在 macOS Keychain 或 Windows CurrentUser DPAPI，不进入网页、扩展、URL 或日志。

内部修复提交为 `9123da7`；从干净公开基线形成的发布提交为 `231dce8`。GitHub `v0.11.1` 已发布为 latest、非 prerelease 的全员测试版，更新清单渠道仍为 `test`，兼容 v0.11.0 更新器。
