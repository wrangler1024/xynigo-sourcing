# 20260825 资源中心店铺与代理 IP P0/P1

## 结论

资源中心已合并新增“店铺管理”和“代理IP”，菜单顺序为买家号库、号商入库、账号注册、环境创建、店铺管理、代理IP。当前实现限定为 P0/P1 只读与本机检测，不执行飞书、HubStudio 或代理资产写入。2026-08-25 已部署 25 项云端权限目录并重启 8771，两个资源页已在真实超级管理员权限下完成浏览器验收。

## 已实现

- 店铺管理：安全字段读取、店铺与代理台账及 HubStudio 全量环境只读对账、显式绑定与名称候选区分、冲突识别、筛选、详情和脱敏 CSV 导出。
- 代理 IP：普通列表跳过账号/密码列，展示脱敏资产；支持筛选、脱敏导出和本机批量健康检测。
- 检测约束：默认并发 10、超时 8 秒、失败复测 1 次，同一端点只检测一次；仅检测明确选择或当前筛选结果，不启动 HubStudio 环境。
- 凭证边界：仅检测任务按需在本机内存读取所选代理凭证；凭证不进入页面、缓存、历史、日志或导出，任务结束后清除引用。
- 权限：新增 8 项 `resource.store.*`、`resource.ip.*` 权限。店铺读取/配置/凭证更新/克隆与代理读取/检测/分配属于管理员日常业务权限；`resource.ip.credential.manage` 固定为超级管理员专属，前后端同时裁决。
- 写入边界：当前没有店铺配置、凭证更新、克隆、代理分配或代理凭证管理写接口，页面明确标记 `writesEnabled=false`。
