# 20260824 前端页面改造完成里程碑

状态：完成

开发分支：`codex/new-ui-migration`

稳定版起点：`f7fd7db`（`v0.9.0`）

里程碑终点：`5e75648`

## 里程碑目标

在不改动现有业务接口和核心执行流程的前提下，把本地开发包迁移到新系统产品层级，并沿用线上 Xynigo 的 UI 风格，为后续云端控制面、权限、运营和财务能力预留稳定入口。

## 已完成范围

### 产品导航

- 一级菜单扩展为：工作台、采购中心、履约追踪、运营中心、财务中心、资源中心、小犀助手、数据分析、系统管理。
- 二级菜单从内容区顶部迁移到左侧边栏，并跟随一级菜单展开。
- 采购协同统一更名为采购中心；采购环境统一更名为环境创建。
- 资源中心保留账号注册和环境创建，并增加买家号库、号商入库。
- 系统管理预留组织权限、登录安全、外部服务、版本与审计入口。
- 小犀助手没有具体需求时仅显示规划说明，不渲染空二级导航。

### 工作区交互

- 现有业务页面支持多 Tab 打开与切换。
- 最多同时打开 10 个业务页签。
- 页签过多时支持横向滚动、页签清单、关闭其他和关闭右侧。
- 关闭当前页签后自动切换到相邻已打开页面，至少保留一个业务页签。
- 规划入口和真实业务页严格分离，规划页不会触发后台请求或真实写入。

### 资源中心与执行安全

- 买家号库从飞书统一台账读取脱敏库存、状态和环境绑定信息。
- 号商入库支持 xlsx 严格解析、飞书字段检查、邮箱/号商单号查重、脱敏预览和二次确认写入。
- 账号注册和环境创建沿用已有后端 API 与业务流程。
- 环境创建后的出口 IP 检查调整为全部新建环境后台无头验证，不打开真实可见 HubStudio 窗口。

## 未纳入本里程碑

- 飞书用户登录、用户会话、组织、角色和模块权限后端。
- Xynigo 云端控制面、本地执行器注册、任务下发和远程审计。
- 采购中心、运营中心、财务中心、工作台、数据分析的真实业务后端。
- 小犀助手的具体效率工具。
- 买家号按环境数量自动抽取、并发预占和超时释放。
- 移动端页面适配和验收。
- 新版 Windows/macOS 绿色包构建与正式版本发布。
