# 20260825 内置管理员与云端配置隔离

## 结论

Xynigo 工作区已新增后端维护的内置 `admin`（管理员）角色。管理员默认拥有当前目录全部日常业务功能和常规管理能力，但固定不具备云端服务配置权限；代理账号/密码管理也按资源中心安全设计列为超级管理员专属高敏能力。更高权限主体为 `super_admin`（超级管理员）。

2026-08-25 已完成云端测试实例部署并单独重启 8771；8767 保持不动。云端实际目录为 `super_admin` 25/25、`admin` 22/25、`member` 0/25，前端角色管理已由原来的“成员、超级管理员”增加“管理员”。真实普通成员闭环仍未执行，因此本次结论是部署完成，不等于正式全员上线。

## 角色与权限规则

| 系统角色 | 默认权限 | 权限策略可编辑 | 云端服务配置 |
|---|---:|---:|---:|
| `super_admin` / 超级管理员 | 25/25 | 否 | 允许 |
| `admin` / 管理员 | 22/25 | 否 | 拒绝 |
| `member` / 成员 | 0/25 | 是 | 默认拒绝，且高敏权限不可授予 |

云端服务配置高敏权限包括：

- `system.lark_connection.manage`：飞书企业应用及业务数据连接配置；
- `system.integration.manage`：后续云端服务/外部集成配置。

资源高敏权限另包括：

- `resource.ip.credential.manage`：代理账号和代理密码管理，只允许超级管理员；代理只读与本机健康检测仍属于管理员日常业务能力。

后端目录同步会自动补齐管理员缺失的非高敏权限，并持续移除管理员角色上的三项高敏权限。超级管理员也不能通过权限策略把这些权限授给普通角色。

## 后端最终裁决

- 前端对管理员隐藏“飞书连接”和“云端服务配置”。
- 本地敏感配置 API 不只检查权限码，还必须检查当前身份含 `super_admin`；即使数据库或缓存误授权限，`admin` 仍返回 403。
- 云端角色权限 API 拒绝把三项高敏权限写入任何非超级管理员角色。
- `admin` 与 `super_admin` 都是系统锁定角色，不能改名、删除或从页面改写权限集。
