# v0.12.0 采购中心与环境创建优化发布

日期：2026-08-26

## 结果

Xynigo Sourcing `v0.12.0` 已发布为 GitHub latest、非 prerelease 的全员协同测试版本。包内更新渠道继续为 `test`，用于当前共享测试环境，不代表生产服务器开放。

- 公开净化分支：`codex/release-v0.12.0-public`
- 公开发布提交：`3ea1ce6 release: prepare v0.12.0 test update`
- 标签：`v0.12.0`
- Release：<https://github.com/wrangler1024/xynigo-sourcing/releases/tag/v0.12.0>

## 发布内容

- 采购任务公共待认领池支持批量勾选认领、店铺/运营筛选及金额、利润、利润率摘要。
- 采购执行改为采购员个人宽屏工作台，统一详情/处理操作，保留符合条件的一单一 SKU 一件快捷下单。
- 未分单、未开始的本人采购单可填写原因后退回公共任务池；服务端拒绝已有分单或已进入后续流程的数据。
- 采购详情按付款批次预留物流单号、物流商和物流状态，持久化与回填接口仍待开发。
- HubStudio Local API 增加 0.3 秒全局请求错峰；`E010205` 限流由所有线程共享 2/4/8 秒递增冷却；环境已创建后的重试会接管半完成环境，避免重复创建。

## 边界

- 本次只发布本机程序与公开源码，没有部署或修改生产服务器。
- 共享测试云端数据库仍为 `0006_purchase_operator`；业务操作日志 P0 和系统运行日志 P1 的迁移/API 未部署。
- 真实采购下单、店小秘审核、SHEIN 写入、飞书同步 Worker 和物流回填仍需后端状态机及单独授权。
- 如本机更新异常，可回退到 v0.11.1 绿色包；回退前保留配置、日志和运行数据，不修改云端采购数据。
