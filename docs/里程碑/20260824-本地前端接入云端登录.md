# 20260824 本地前端接入云端登录

状态：开发完成，隔离测试环境真实闭环已验证；正式绿色包尚未发布

开发分支：`codex/new-ui-migration`

## 目标

在不改变 HubStudio 本机执行边界的前提下，为 Xynigo 本地开发包增加“小犀代采”飞书扫码登录，使后续运营采购助手、运营中心和财务中心能够共享云端用户、角色、权限和会话事实源。

## 已完成

- 云端新增 `local_login_requests`，登录请求 5 分钟过期、摘要存储、数据库行锁和单次消费。
- 飞书回调批准本地登录后，由本地 Python 服务轮询换取 Bearer 会话；网页拿不到轮询令牌和会话令牌。
- macOS 会话保存到系统钥匙串，Windows 保存到 CurrentUser DPAPI 加密文件；退出时同时撤销云端会话并清理本机存储。
- 本地页面新增登录门禁、飞书扫码入口、等待状态、当前成员和退出按钮，保持现有 Xynigo UI 风格不变。
- 现有二级菜单按云端权限摘要显示；资源中心、履约导出和飞书连接可分别屏蔽。
- 本地业务接口不再只依赖前端隐藏，履约、买家号入库、账号注册、环境创建和飞书连接均增加后端权限校验。
- 本机所有 POST API 增加浏览器同源校验，阻止外部网页借已登录的本地执行器发起跨站写入；不带 Origin 的原生客户端与既有本机脚本保持兼容。
- 新增 `/api/lark/status` 脱敏只读状态；普通用户可判断业务回写是否就绪，但不能读取应用凭证状态、打开配置目标或修改连接。
- 公网 Nginx 为本地登录创建接口增加独立限流。
- 顶部账号入口移至 HubStudio 状态之后；窄屏使用头像按钮与下拉菜单展示姓名、角色和退出，头像图片与姓名缩写不会同时叠加。

## 权限映射

| 功能 | 权限码 |
|---|---|
| 订单物流查询 | `fulfillment.order.read` |
| 履约结果导出 | `fulfillment.order.export` |
| 买家号库 | `resource.buyer.read` |
| 号商入库、账号注册 | `resource.buyer.import` |
| 环境创建 | `resource.environment.create` |
| 飞书连接 | `system.lark_connection.manage` 且角色为 `super_admin` |

本机设置仍对已认证用户开放，因为采购分组和查询显示配置同时被现有业务流程使用。后续如需独立授权，应先拆分“个人偏好”和“机器级执行配置”接口，再增加权限码。

## 成员准入现状

- 飞书应用可用范围决定能否发起授权，云端租户白名单决定企业是否被接受。
- 新企业成员首次授权默认创建 `pending` 用户，不签发系统会话；`auto_activate_users` 默认关闭。
- 只有明确配置的超级管理员会在首次登录时激活并初始化系统权限。
- 普通成员必须经过管理员批准和角色授权后才能登录；当前管理员 API 和页面尚未开发。
