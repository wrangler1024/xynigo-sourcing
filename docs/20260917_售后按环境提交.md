# 采购售后：指定订单按环境提交

基线 `b04d3ac`（包含按环境回访的本地候选）。本次仅本地开发，尚未推送、部署或操作真实订单。

“订单处理 → 本次提交 → 指定订单提交”默认按环境序号输入，支持空格、中英文逗号/分号及换行，去重后最多300个环境。原“环境序号＋订单号”方式保留在“按订单号（完整信息）”选项中。

点击“按环境提交”首先创建现有只读扫描任务。扫描完成后列出每个环境的订单、送达日期、件数、可提交状态与排除原因；最多500单，用户确认后才创建现有售后提交Run。确认清单涵盖本次扫描结果，不受待处理列表的日期或件数筛选影响；需要筛选时可返回列表勾选。

## 提交保护

- 环境顺序沿用输入顺序，同一环境多订单分别展示；订单归属在多个环境间冲突或重复行核验结果矛盾时排除。
- 仅纳入本次扫描明确可申请、状态ok、且没有已有提交/退款凭证/待核对保护的订单；商品图数组、商品明细、件数等原字段完整投影。
- 扫描失败、停止、结果不确定、连续五次轮询失败时清除本次自动进入确认步骤的意图；停止请求即解除该意图，即使扫描随后成功也不会触发提交。
- 取消确认、刷新页面、普通扫描完成均不会自动创建提交。意图只存本页内存，与具体扫描任务ID和执行器ID绑定。
- 确认前后比较扫描清单及提交保护；清单内容变化时拒绝提交。扫描和提交执行器不一致时要求重新扫描。
- 最终沿用 `asSubmitItems` 的忙碌/类型闸门、幂等键和原云端接口，执行器仍现场核验平台资格，页面不会把历史记录直接当作可申请依据。
