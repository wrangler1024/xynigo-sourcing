# 采购售后无头与并发设置

基线：6d46bd6。分支：codex/after-sale-runtime-controls。依赖前序吸顶条、售后提示间距与导出入口的本地提交。独立工作区实现，未合并、未发布。

## 用户口径

整个采购售后模块默认无头；“显示浏览器窗口”开关打开后使用有头模式。环境并发按钮为 1 / 2 / 3 / 5，用户指定默认 2。扫描、提交（含直接提交与重提）、回访（含指定单与历史入口）共用设置。运行中锁定控件，每次发起前捕获参数，刷新页面恢复默认值。

## 实现与边界

Web → 三套云端创建契约 → 任务 payload → 本地任务桥接 → 本地 HTTP 路由 → AfterSaleClaimer 全链传递模式与并发数。修正显式 headless 仍受旧本地默认值影响的问题。线程池限制环境并发；同一环境内逐单执行，识别到同一环境的别名通过锁串行，停止后不启动等待中的环境。

新增 after.sale.runtime-controls.v1 能力门槛，旧执行器明确提示升级，不静默忽略设置。需要先部署云端兼容契约，再发布新版执行器；本次不部署、不发布、不操作真实订单。正在使用的既有可见窗口仍按原规则复用，不强制关闭重开。

本分支未包含其他工作区正在进行的“所有订单扫描”等修复。后续合并应核对 after_sale_claim.py、main.py、operation_executor.py 及 Web 的重叠修改；不得用本分支覆盖其他任务成果。

## 验证

本地售后/桥接/执行器通道/Web 相关套件 196 项通过；另增发起时参数捕获 4 项通过。云端售后与运行参数套件 22 项通过。

合成测试覆盖默认无头与并发 2、显式可见、1/2/3/5 并发上限、同环境串行和别名互斥、停止不启动后续环境、桥接经过真实本地 Handler 的参数透传、三套云端任务领取载荷、参数非法值、旧能力阻断、幂等参数冲突。

Web 实际函数合成测试覆盖三入口共用设置、运行中控件锁定、旧能力提示、发起时参数快照。Chrome 离线页面在 1440/480 宽度验证开关、按钮选择、禁用和无横向溢出。未运行真实平台退款操作；上线与业务验收需单独执行。
